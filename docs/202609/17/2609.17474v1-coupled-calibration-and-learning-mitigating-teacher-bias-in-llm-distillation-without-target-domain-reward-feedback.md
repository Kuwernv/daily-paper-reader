## 摘要
大语言模型（LLM）蒸馏旨在将强大教师模型的能力迁移到较小的学生模型。然而，直接模仿也可能迁移教师的系统性偏差和错误。这一挑战在协变量偏移下尤为突出：此时教师模型在目标问题上的可靠性不确定，且无法获得目标域的奖励反馈。我们提出耦合校准与学习（CCL），一种 LLM 蒸馏算法，它通过 token 级分支将教师校准与学生更新耦合起来，且仅在源问题上使用奖励反馈。每次迭代使用源反馈校准教师，然后利用校准后的教师在目标问题上训练学生。更新后的学生反过来又为后续校准提供信息。在自回归策略框架中，我们证明输出学生与 oracle 学生之间的期望平均 Kullback-Leibler 散度以迭代次数的多项式速率收敛到零。该 oracle 在学生类内最大化真实的参考正则化目标奖励，而不必代表无限制的最优策略。我们的分析量化了投影学生梯度更新的进展，同时控制了教师校准中的误差。我们进一步建立了与正则化直接匹配的分离：即使教师达到的正则化目标奖励高于每个学生策略，其相对于 oracle 学生的误差仍可能保持有界地远离零。这些结果表明，LLM 蒸馏可以通过耦合校准与学习克服持续存在的教师偏差，并在没有目标域奖励反馈的情况下恢复最优学生。

## Abstract
Large language model (LLM) distillation aims to transfer the capabilities of a powerful teacher to a smaller student. Direct imitation, however, can also transfer the teacher's systematic bias and errors. This challenge is particularly pronounced under covariate shift, when the teacher's reliability on target questions is uncertain and target-domain reward feedback is unavailable. We propose Coupled Calibration and Learning (CCL), an LLM distillation algorithm that couples teacher calibration with student updates through token-level branching, using reward feedback only on source questions. Each iteration calibrates the teacher using source feedback and then uses the calibrated teacher to train the student on target questions. The updated student, in turn, informs subsequent calibration. In an autoregressive policy framework, we prove that the output student's expected average Kullback-Leibler divergence to the oracle student converges to zero at a polynomial rate in the number of iterations. The oracle maximizes the true reference-regularized target reward within the student class, which need not represent the unrestricted optimal policy. Our analysis quantifies the progress of projected student gradient updates while controlling the error in teacher calibration. We further establish a separation from regularized direct matching: its error relative to the oracle student can remain bounded away from zero even when the teacher achieves higher regularized target reward than every student policy. These results demonstrate that LLM distillation can overcome persistent teacher bias and recover the optimal student through coupled calibration and learning, without target-domain reward feedback.

## 1. 核心问题与整体含义

- **研究背景**：LLM 蒸馏旨在将强大教师模型的能力迁移到小规模学生模型，但直接模仿会同时迁移教师的系统性偏差与错误。
- **关键挑战**：在**协变量偏移（covariate shift）**下，目标问题与源问题分布不同，教师在目标问题上的可靠性无法保证；更困难的是，**目标域完全没有奖励反馈**（reward feedback），仅有源问题上的可信奖励监督可用。
- **核心问题**：能否在仅有源域奖励反馈、目标域无任何奖励反馈的条件下，从有偏教师中蒸馏出接近最优的学生模型？

## 2. 方法论

### 2.1 核心思想
- **耦合校准与学习**：将"教师校准"与"学生更新"通过 **token 级分支（token-level branching）** 交替耦合：
  - 用源域奖励反馈校准教师，使其逼近正则化最优策略；
  - 用校准后的教师在目标问题上训练学生；
  - 更新后的学生反过来为下一轮校准提供 token 替代样本。
- **关键洞察**：校准参数在源域与目标域共享（Assumption 3.2 可实现性），因此源域学到的校准可迁移到目标域蒸馏目标中。

### 2.2 模型设定
- 将自回归生成建模为有限时域 token 级 MDP：M = (S, A, P, R, H)。
- 策略采用线性-softmax 参数化：π_w(a|s) ∝ exp(wᵀφ(s,a))，学生类 π_stu,θ 同理。
- 目标函数为参考正则化目标：
  - J_{λ,m}(π) = (1/m) Σ_j E[R(x̃_j, a) − λ·KL(π(·|x̃_j) ‖ π_pre(·|x̃_j))]
- **Benchmark（oracle 学生）**：在学生类 Θ 内最大化真实目标 J_{λ,m} 的参数 θ†_{λ,m}，不要求学生类能表示无限制最优策略 π*_λ。

### 2.3 关键技术细节
- **Token 级分支**：在教师生成答案的随机位置，保留前缀，比较教师下一 token c_{t,1} 与学生采样 token c_{t,0}；用参考策略按概率选择分支并用 π_pre 补全后缀，查询源奖励 R_t。
- **接受规则**：I_t = 1{U_t ≤ exp((R_t − 1)/λ)}，使得接受后分支索引满足 logistic 模型：
  - Pr(Y_t = 1 | I_t = 1) = σ(z_tᵀ w*_λ)，z_t = φ(s_t,c_{t,1}) − φ(s_t,c_{t,0})
- **校准更新**：g_t = I_t z_t[σ(z_tᵀ w_t) − Y_t]，w_{t+1} = Proj_W(w_t − η_t g_t)，即接受加权的 logistic 梯度。
- **学生更新**：用当前学生 rollout 估计 C_{t+1}(θ) = λ/m Σ KL(π_stu,θ ‖ π_cal,t+1) 的梯度，形成投影梯度候选；同时均匀采样一个随机候选，用新鲜目标 rollout 评估两者代价并选优（类似探索+利用）。
- **步长调度**：η_t = 1/[γ(t+2)]，α_{t+1} = α_stu = 1/(2L_st)，b_{t+1} = t+2，q_{t+1} = (t+2)²；每轮恰好 1 次源奖励查询，总目标 rollout 为 O(T³)。

### 2.4 理论保证
- **定理 5.1（收敛）**：CCL 输出学生到 oracle 学生的期望平均 KL 以多项式速率收敛：
  - E[K_{λ,m}(θ_T)] ≤ C_{λ,m}(T+1)^{−1/(4p_{λ,m})}
- 证明要点：
  - 源校准误差 E[‖w_t − w*_λ‖²] ≤ 4/[γ²(t+2)]；
  - 近 oracle 区域用局部 Łojasiewicz 不等式 + 投影梯度提供二次下降；
  - 远离区域用均匀探索提供固定概率的改进；
  - 控制梯度估计、校准、验证三类误差；
  - 再用第二个 Łojasiewicz 不等式将 excess cost 转为 oracle-policy KL。

### 2.5 分离定理
- **定理 6.2（分离）**：构造 LLM-as-judge 目标实例（H=2，d 维，α∈[1/2,1)），证明正则化直接匹配（Algorithm 2）的误差下界：
  - E[KL(π_stu,θ^SM_T ‖ π_stu,θ†)] ≥ (κ_SM/2d)[√d(1−α)/(4λ) − G_SM/(μ_SM√(T+1))]²_+
- 即使教师 J_{λ,m}(π_tea) 高于所有学生策略，直接匹配仍保留非零误差；CCL 则可消除该误差。

## 6. 主要结论与发现

- CCL 能够在**仅有源域奖励反馈、目标域无奖励反馈**的条件下，从有偏教师中恢复学生类内的最优 oracle 学生。

- 结论：教师偏差不必然造成不可消除的损失，源域奖励反馈足以纠正目标域蒸馏方向。
