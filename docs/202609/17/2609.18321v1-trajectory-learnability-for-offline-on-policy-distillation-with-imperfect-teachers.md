## 摘要
离线同策略蒸馏通过一次性收集学生轨迹和教师监督，并在整个优化过程中重复使用它们来获得效率。这种重复使用也使得不完美的监督持续存在。由于即使强大的教师也可能失败，我们提出：从不完美的教师监督中，什么仍然是可学习的？教师失败只是一个粗粒度的问题级信号，并不意味着相关学生轨迹上的所有监督都无益。一个自然的替代方案是估计教师沿轨迹的可恢复性，但重复续写会在很大程度上抹去离线蒸馏的效率优势。我们转而使用教师成功的问题来定义一个廉价的参考，以衡量学生能够学习什么。我们在教师成功的问题上训练，并测量来自教师失败问题的轨迹中每个观测 token 的似然如何变化。我们将这些带符号的似然变化用作一种可操作的“可学习性信号”：增幅越大，表明该行为越受到仅成功学习的有力促进。我们将该信号聚合为轨迹级权重，用于原始蒸馏损失。与基于续写的估计不同，我们的可学习性不需要额外生成，并且可以从存储的轨迹和模型检查点一次性计算得到。在数学推理和代码生成任务上，我们的方法将离线 OPD 基线最多提升 2.7 个百分点，并在多个基准上达到或超过在线 OPD 变体。尽管增加了仅成功蒸馏阶段，它仅使用 2 块 GPU 和约 22 GPU 小时，而代表性的在线 OPD 方法使用 3 块 GPU 和 36–48 GPU 小时。

## Abstract
Offline on-policy distillation gains efficiency by collecting student trajectories and teacher supervision once and reusing them throughout optimization. The same reuse makes imperfect supervision persistent. Since even strong teachers can fail, we ask \emph{what remains learnable from imperfect teacher supervision?} Teacher failure is only a coarse problem-level signal and does not imply that all supervision along the associated student trajectory is unhelpful. A natural alternative is to estimate teacher recoverability along the trajectory, but repeated continuations largely erase the efficiency advantage of offline distillation. We instead use teacher-successful problems to define a cheap reference for what the student can learn. We train on teacher-successful problems and measure how the likelihood of each observed token in trajectories from teacher-failed problems changes. We use these signed likelihood changes as an operational \emph{learnability signal}: larger increases indicate behavior more strongly promoted by successful-only learning. We aggregate this signal into trajectory-level weights for the original distillation loss. Unlike continuation-based estimates, our learnability requires no additional generation and can be computed once from stored trajectories and model checkpoints. Across mathematical reasoning and code generation, our method improves an offline OPD baseline by up to 2.7 percentage points and matches or outperforms online OPD variants on multiple benchmarks. Despite the additional successful-only distillation stage, it uses 2 GPUs and about 22 GPU hours, compared with 3 GPUs and 36--48 GPU hours for representative online OPD methods.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）让学生在自身生成的轨迹状态上接受更强教师的稠密 token 级监督（Agarwal et al., 2024）。其**离线变体**（如 Lightning-OPD, Wu et al., 2026）一次性收集学生轨迹与教师监督并在整个优化过程中反复复用，从而大幅降低生成与教师推理开销。
- **核心矛盾**：同一份复用也让**不完美的监督持续存在**——一旦不可靠的教师指导进入离线训练集，它会在多轮优化中反复塑造学生。即使强教师也会失败。
- **关键问题**：*从不完美的教师监督中，什么仍然是可学习的？*
- **对"教师失败"的重新审视**：
  - 教师失败只是**问题级（problem-level）粗粒度信号**；教师结果来自独立生成的教师回答 `y_T`，而蒸馏监督提供在学生访问的状态上——二者是**不同的东西**。
  - 教师 rollout 失败**不意味着**学生轨迹上每个条件教师目标都无用。全部丢弃会丢失有用监督；全部保留（权重=1）则忽略了失败所携带的信息。
  - 同样被标为"教师失败"的学生轨迹，其推理行为可能差异很大（见图 1(a)），因此问题不是"留还是弃"，而是"**每条轨迹该保留多少**"。
- **为何不直接估计可恢复性**：沿多个前缀反复续写并验证教师能否恢复成功解，其粒度成本会**抹平离线蒸馏的效率优势**（图 1(b)）。
- **论文定位**：提出一种**廉价、可操作的可学习性信号**，在保持离线效率的前提下为教师失败轨迹分配差异化监督强度。

## 2. 方法论：Learnability-Weighted Distillation (LWD)

### 2.1 核心思想
用**教师成功题上的学习过程作为参照**（successful-only learning），观察该更新如何改变教师失败题轨迹上已观测 token 的似然；似然**有符号变化**即作为 token 级可学习性信号，再聚合成轨迹级权重去重加权原始 OPD 损失。全程**无需额外生成**，只需对存储轨迹做两次前向。

### 2.2 四个阶段

**阶段 1：离线记录与教师结果**
- 固定学生策略 ρ 生成轨迹 `τ_i = (a_{i,1},…,a_{i,T_i}) ∼ ρ(·|x_i)`，状态 `s_{i,t} = (x_i, a_{i,<t})`。
- 冻结教师 π_T 提供 token 级监督，记为 token 损失 `d_{i,t}(θ)`。
- 教师独立生成一条回答 `y_i^T`，用领域成功判定函数得到 `c_i = 1[SUCC(y_i^T, x_i)]`，划分 `D+ = {i: c_i=1}`、`D− = {i: c_i=0}`。
- 强调：`c_i` 既**不标注**学生轨迹 τ_i 的正确性，也**不标注**学生访问状态上教师目标的质量。

**阶段 2：仅成功参考模型（Successful-Only Reference）**
- 从 ρ 出发，**仅用 D+** 的记录做同样的蒸馏，训练得到 `π+ = π_{θ+}`（实现中为 150 次优化更新）。
- D− 记录被排除在该更新之外，因此可用于"考察仅成功学习如何改变教师失败题上的行为"。

**阶段 3：Token 级可学习性信号**
- 定义 `ℓ_{i,t} = log π+(a_{i,t}|s_{i,t}) − log ρ(a_{i,t}|s_{i,t})`（i ∈ D−）。
- 正值表示仅成功学习**提升**了该已观测学生 token 的似然；负值表示降低。
- 该信号**不判断 token 对错**，也不估计该状态上教师目标的效用，只度量观测到的学生行为对"仅成功学习"的响应。
- 轨迹均值有精确恒等式：`ℓ̄_i = (1/T_i)·log[π+(τ_i|x_i)/ρ(τ_i|x_i)]`；一阶展开 `ℓ̄_i ≈ Δθᵀ∇θ f_i(θρ) + O(‖Δθ‖²)`，即近似反映"仅成功更新方向"与"提升存储轨迹似然方向"的对齐度。

**阶段 4：轨迹级可学习性加权**
- **粒度选择理由**：可学习性信号与 OPD 损失度量的是不同量——前者是"学生实际生成 token 的似然变化"，后者是"把学生拉向教师分布"。低信号处恰恰可能是学生偏离、需要纠正性教师监督的地方；直接在 token/span 级重加权会不必要地改变原 token 级监督结构。故选择**轨迹级聚合**。
- 先对 ℓ 做 **33-token 滑动平均平滑**（并将 ℓ 裁剪到 [−4, 4]），再计算轨迹**均值 m_i**（整体支持强度）与**方差 v_i**（支持稳定性）。
- 在 D− 内做长度加权标准化得 `z_m^i`、`z_v^i`，映射为三档序数层级：
  - `low`：`z_m ≤ −0.5` **或** `z_v ≥ 1.0`（弱/不稳定）
  - `high`：`z_m ≥ 0.5` **且** `z_v < 1.0`（强且稳定）
  - `mid`：其他
- 名义权重 `ω_low=0.15 < ω_mid=0.25 < ω_high=0.35`；再用一个全局缩放因子使 D− 上**响应 token 加权平均权重 ≈ ω_0 = 0.25**，并裁剪到 [0.15, 0.35]，使 D− 的总监督量与"共享降权"基线相当，只是重新分配。
- 最终目标：`w_i = 1 (c_i=1) 或 ω_{b_i} (c_i=0)`；`L_LWD(θ) = Σ_i w_i Σ_t d_{i,t}(θ)`。由于 `w_i` 在轨迹内共享，**保留了 token 级教师目标及其相对结构**。
