## 摘要
同策略蒸馏（OPD）已成为大语言模型后训练的一种有效方法，但现有目标面临目标保真度与优化稳定性之间的权衡。词元级 OPD 提供稳定但局部的监督，而序列级 OPD 能捕捉未来信用，但代价是随视界变化的方差。我们为这些形式建立统一的时序信用视角，表明实际的词元级 OPD 可被解释为对序列级反向 KL 梯度的一种时序近似。基于这一联系，我们提出 γOPD，它使用折扣时序信用分配来平衡长视界监督与优化稳定性，同时具有与视界无关的方差上界。我们进一步为 γOPD 开发了一种奖励兼容的有界混合（RBM）机制，该机制平衡可验证结果反馈与折扣 OPD 优势，从而超越纯粹依赖教师的优化。在数学与代码推理任务上的实验表明，在标准、规模不匹配和多教师蒸馏设置中，该方法相较现有 OPD 方法均取得一致提升。

## Abstract
On-policy distillation (OPD) has emerged as an effective approach for large language model post-training, yet existing objectives face a trade-off between objective fidelity and optimization stability. Token-level OPD provides stable but local supervision, whereas sequence-level OPD captures future credit at the cost of horizon-dependent variance. We establish a unified temporal-credit view of these formulations, showing that practical token-level OPD can be interpreted as a temporal approximation to the sequence-level reverse-KL gradient. Building on this connection, we propose $γ$OPD, which uses discounted temporal credit assignment to balance long-horizon supervision and optimization stability, while admitting a horizon-independent variance bound. We further develop a reward-compatible bounded mixing (RBM) mechanism for $γ\mathrm{OPD}$ that balances verifiable outcome feedback with the discounted OPD advantage to move beyond purely teacher-dependent optimization. Experiments on mathematical and code reasoning demonstrate consistent improvements over existing OPD methods across vanilla, size-mismatched, and multi-teacher distillation settings.

## 1. 核心问题与整体含义

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）已成为大语言模型后训练的关键手段——在学生自身采样出的推理轨迹上最小化到教师分布的反向 KL，从而提供稠密监督并缓解 exposure bias，适用于长链式思维推理。
- **核心矛盾**：现有 OPD 实现面临**目标保真度 vs. 优化稳定性**的权衡。
  - 为避免全词表反向 KL 的高成本，主流做法把目标改写成策略梯度形式，用**单样本词元级 Monte Carlo 估计**（即 `A_t = log π* − log πθ`）。计算高效，但相对序列级原目标存在不可忽略的偏差，实质上改变了优化问题。
  - 另一路线采用**序列级 Monte Carlo** 更忠实地保留原目标，但把未来信用累积到当前词元上，方差随剩余序列长度增长，长推理轨迹训练不稳定。
- **整体含义**：论文给出 OPD 的**统一时序信用视角**，指出实用词元级 OPD 只是序列级反向 KL 梯度的"时序截断近似"；并在此基础上提出 γOPD 与奖励兼容有界混合（RBM），在保留稳定性的同时引入长程信用与任务级可验证信号，使蒸馏可以**超越纯教师模仿**。

## 2. 方法论

### 2.1 统一时序信用视角（理论起点）
- 定义两个目标：序列级 `J_seq_OPD = E[D_KL(πθ(y|x) ‖ π*(y|x))]`；词元级 `J_token_OPD = E[Σ_t E_{h_t∼d̄θ}[D_KL(πθ(·|h_t) ‖ π*(·|h_t))]]`，其中 `d̄θ` 表示前缀分布**停止梯度**。
- 当 `θ̄ = θ` 时两者**函数值等价**，但**梯度不等价**（关键洞察）。
- **命题 3.1**：`∇J_token = E[Σ_t Δ_t ∇log πθ(y_t|h_t)]`，`Δ_t = log πθ(y_t|h_t) − log π*(y_t|h_t)`，正是实用 OPD 的更新式。
- **命题 3.2**：`∇J_seq = E[Σ_t (Σ_{t'=t}^{T} Δ_{t'}) ∇log πθ(y_t|h_t)]`，即每个词元的 score 项被"未来 log-ratio 回报"加权；词元级版本只保留局部 `Δ_t`。

### 2.2 γOPD：折扣时序信用分配
- 引入折扣因子 `γ ∈ [0,1]`，定义折扣优势：
  `A_t^(γ) = − Σ_{t'=t}^{T} γ^{t'−t} Δ_{t'}`
- 两个端点：`γ=1` 恢复序列级 return-to-go（式 6）；`γ=0` 退化为词元级优势 `−Δ_t`（式 5）。中间值构成**有偏但可控的插值代理梯度**。
- **定理 3.3（方差稳定性）**：在词元级优势二阶矩有界（`E[(A_t^(0))²] ≤ σ²_∆`）假设下：
  - 序列级：`Var(A_t^(1)) ≤ (T−t+1)² σ²_∆`（最坏情况随剩余视界**二次增长**）；
  - γOPD：`Var(A_t^(γ)) ≤ σ²_∆/(1−γ)²`，对任意固定 `γ<1` 均**与视界无关**。
- 因此 `γ` 成为稳定性与长程信用传播之间的**原则性调节旋钮**。

### 2.3 奖励兼容有界混合（RBM）
- 动机：γOPD 仍完全源自教师分布，学生受教师上限约束，缺少任务级信号。直接混入可验证奖励 `R(x,y) ∈ {−1,+1}` 会被量级差异大的教师优势淹没。

- 性质：第一项在 `A_t^(γ)` 上单调且界于 `(−1,1)`，保留词元级相对信用，同时防止教师信号压倒任务奖励；由于 `R ∈ {±1}`，有 `sign(Â_t^(γ)) = R(x,y)`，即**构造上即"奖励兼容"**——可验证奖励决定强化/抑制方向，有界 OPD 信用只调制更新强度。
