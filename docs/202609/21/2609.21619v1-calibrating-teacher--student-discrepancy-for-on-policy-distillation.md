## 摘要
同策略蒸馏（OPD）通过学习更强教师模型与同策略学生模型之间的词元级差异来改进推理模型。然而，这种差异并不纯粹反映教师与学生之间的能力差距：它还包含源自教师本身的偏差，这些偏差因此被混入观测到的教师—学生差异中，并在训练期间被标准 OPD 不加区分地学习。特权 OPD 进一步加剧了这一问题：特权信息会引发更大的教师侧似然偏移，从而促使学生学习更多教师自身的偏差。我们提出校准同策略蒸馏（Calibrated On-Policy Distillation, Cal-OPD），其通过正向和负向特权干预来估计教师的自偏差区域，并通过仅保留位于该区域之外的分量来校准原始的教师—学生差异。在数学推理基准上的实验表明，尽管仅保留原始教师—学生差异的约 52–65% 作为优化信号，Cal-OPD 在不同模型规模上仍持续优于标准 OPD 及其变体。

## Abstract
On-policy distillation (OPD) improves reasoning models by learning the token-level discrepancy between a stronger teacher and an on-policy student. However, this discrepancy does not purely reflect the capability gap between the teacher and the student: it also contains deviations arising from the teacher itself, which are consequently mixed into the observed teacher--student discrepancy and indiscriminately learned by standard OPD during training. This issue is further exacerbated by privileged OPD, where privileged information induces larger teacher-side likelihood shifts, thereby encouraging the student to learn more of the teacher's own deviation. We introduce \textbf{Calibrated On-Policy Distillation (Cal-OPD)}, which estimates the teacher's self-deviation region through positive and negative privileged interventions and calibrates the original teacher--student discrepancy by retaining only the component that lies beyond this region. Experiments on mathematical reasoning benchmarks show that, while retaining only about 52--65\% of the original teacher--student discrepancy as the optimization signal, Cal-OPD consistently outperforms standard OPD and its variants across model scales.

## 一、核心问题与研究动机

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）通过在学生自己生成的轨迹上，用教师—学生的词元级对数似然差（`A^OPD_t = ℓ^T_t − ℓ^S_t`）作为稠密监督信号，来提升推理模型，相比依赖稀疏结果奖励的 RLVR 更直接高效；Qwen3 等大规模推理后训练已采用该范式。
- **核心问题**：标准 OPD 隐含假设“教师对每个学生词元赋予的似然都是同等可靠的参照”，但教师似然实际上具有**词元特异性波动**。作者将此现象命名为**教师自偏差（Teacher Self-Deviation, TSD）**。
- **后果**：观测到的师生差异 = 真实能力差距 + 教师自身偏差。标准 OPD 不加区分地学习二者，相当于把教师侧噪声也当作知识蒸馏给学生。
- **特权 OPD 的加剧效应**：特权 OPD（教师额外条件于参考答案、最终答案、提示等）会引发更大的教师侧似然偏移，进一步放大 TSD，导致信息不对称、捷径行为，甚至使 thinking 模型性能下降。
- **整体含义**：有效蒸馏的关键不在于“学更多师生差异”，而在于**识别哪些差异真正值得学习**；特权信息应当用于**校准教师参照**，而非直接监督学生。

## 二、方法论：Calibrated On-Policy Distillation（Cal-OPD）

### 1. 核心思想
将观测到的师生差异分解为两部分：

```
A^OPD_t（师生差异） = A^Cal_t（校准后差异） + A^TSD_t（TSD 解释的差异）
```

只保留**超出教师自偏差区域之外**的残差作为优化信号。

### 2. TSD 的定义与估计（有限干预近似）
- 对固定问题 `x`、学生 rollout `y` 与前缀 `y_<t`，仅对教师施加**上下文干预 `c`**，保持被评估轨迹不变，定义似然变化：`Δ^T_t(c) = ℓ^T_t(c) − ℓ^T_t(c_0)`。
- 给定干预集合 `C`，估计向下/向上偏差幅度：`d̂↓_t = max(0, −min_{c∈C} Δ^T_t(c))`，`d̂↑_t = max(0, max_{c∈C} Δ^T_t(c))`。
- 由此得到经验 TSD 区域：`R̂^T_t(C) = [ℓ^T_t − d̂↓_t, ℓ^T_t + d̂↑_t]`，明确其为**有限干预下的近似**，而非穷尽所有上下文变化。

### 3. 校准机制（关键技术细节）
- 使用**正/负对比干预** `c_pos`、`c_neg`（论文实测中 `C_eval` 效果最佳），计算 `Δ^pos_t`、`Δ^neg_t`。
- 引入**松弛因子 λ ≥ 1** 扩大估计区域以补偿仅两次探针的有限性：`R̂^T_t = [L^T_t, U^T_t] = [ℓ^T_t − λd̂↓_t, ℓ^T_t + λd̂↑_t]`。
- 校准优势函数：

```
A^Cal_t = [L^T_t − ℓ^S_t]_+ − [ℓ^S_t − U^T_t]_+ ,   [z]_+ = max(z,0)
```

  - 若学生似然落在估计区域内（`ℓ^S_t ∈ R̂^T_t`），则该词元的优势被**置零**（视为 TSD 已解释）。
  - 否则仅保留超出最近边界的残差部分。
- 训练目标沿用标准 OPD 形式，仅把 `A^OPD_t` 替换为 `A^Cal_t`；干预只用于估计区域，**不直接蒸馏进学生**。

### 4. 干预类型（Table 1）
任务无关指令（`inst`）、评价性反馈（`eval`）、答案级特权（`ans`）、解级特权（`sol`），每组均含正负变体；负解变体经长度匹配（与正解 token 长度差 <10%）以排除长度干扰。

## 六、主要结论与发现

1. **TSD 的存在性与性质（诊断发现）**：
   - **无任务知识也会出现**：在 τ=0.01 时，任务无关指令的正/负变体分别在 20.2%/25.8% 词元上产生显著 TSD，并集 29.8%，与评价性反馈（29.1%）、答案级特权（29.4%）相当；解级特权扩至 39.6%。
   - **位置保留的不对称性**：低信息量干预下显著的词元，在解级特权下保留率高达 98% 左右；反向仅约 73%。说明更丰富特权是**扩展**而非重建偏差模式。
   - **对语义与正确性不敏感**：正负对照的位置重叠 61–80%、方向一致率 79–89%、共享偏差比（SDR）66–75%；即使反转答案正确性，方向一致率仍达 88.7%。说明 TSD 不能可靠解释为任务知识信号。
   - **集中于表层形式词元**：高 TSD 词元以 `maybe / however / therefore / consider / alternatively / wait` 等自然语言话语标记为主（显著率 >89%），低 TSD 词元以数字、数学符号（`0 / √ / θ / frac`）为主（<9.3%），相差近一个数量级。
   - 上述结论在多个阈值与两种教师规模下均可复现。

2. **方法效果**：
   - Cal-OPD 在两组配置下平均分最高：53.1（4B→1.7B）与 69.0（30B→4B），分别比学生基线 +3.9 / +2.4，比标准 OPD +2.3 / +3.1。
   - 标准 OPD 在 4B→1.7B 仅从 49.2 提升到 50.8，在 30B→4B 甚至从 66.6 降到 65.9——**原始师生差异并非一致有益的监督**。
   - Privileged-OPD 表现最差（49.3 / 64.0），说明直接蒸馏特权教师会连同教师侧偏差一起传递。
   - **仅保留约 52–65% 的原始差异**即可获得更好性能；零优势词元比例从 27% 升至 34%。

3. **训练动态**：Cal-OPD 抑制了标准 OPD 的响应长度膨胀（OPD 约 9.8K→11.8K，Cal-OPD 收敛于约 9.3K），并保持更高熵；Top-16 token 重叠更高（约 0.693）但概率质量重叠更低，说明学生覆盖更多教师支持的合理推理模式而非过度拟合单一主导分布。

4. **校准强度需适中**：`C_eval` 最佳（53.1）；`C_inst` 校准太弱、近似退化为标准 OPD；`C_sol` 校准过强、平均分降至 49.0（约只保留 20% 差异），出现“信号崩溃”。λ=5 最优，λ 增大到 80 时性能低于 λ=1 基线 1.7 分。

## 七、优点（亮点）

- **问题诊断新颖且有说服力**：把“教师监督不可靠”从不确定性、位置、结果等既有视角，重新形式化为**受控上下文干预下的教师似然波动区域**，并用大规模（~6,000 万词元 × 9 上下文）实证刻画其四个关键性质。
- **方法简洁、无需额外训练**：TSD 区域仅由两次对比干预的前向打分估计，不引入额外模型、不改变 OPD 优化框架，实现成本可控。
- **设计严谨的对照实验**：保留率匹配对照（Advantage-Sync / Token-Sync / TSD-Filter）有力排除了“收益来自信号衰减或稀疏化”的替代解释。
