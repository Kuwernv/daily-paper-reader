## 摘要
在策略自蒸馏（OPSD）让语言模型从一个冻结的自身副本中学习，而该副本能看到答案或完整的解题过程。将这种额外信息提供给教师，似乎能让学生学到更多，但它相较蒸馏本身究竟带来了多少增益？为分离这一贡献，我们构建了 AMPLE-Math，这是一个可复用的数学问题套件，包含 5,319 道数学题和六种推理视角，且这些视角共享同一答案，并将每种视角与匹配的无参考蒸馏进行比较。在启用思考的教师监督直接回答式 rollout 时，无参考蒸馏解释了 Qwen3-1.7B 在启用思考的评估下的大部分提升，无论是在领域内还是外部基准上。额外参考益处的证据在 Qwen 中较为有限，对精炼解答最强，而完整轨迹在 SmolLM3-3B 第 50 步时带来两个百分点的提升。这些收益取决于所训练的学生。在同一检查点，将短直接回答式 rollout 替换为长思考式 rollout，会在两个模型系列中把增益变为损失，而问题、参考和评估保持不变。Qwen 中的教师画像和匹配损失干预进一步表明，改变 token 级监督可能使学生的行为基本不变。总之，这些发现表明，OPSD 可以通过直接回答式推理和思考式推理共享的参数，改善对已有推理能力的获取。特权参考的价值在于它能为这种跨模式迁移增添什么，而不在于它揭示了多少解题过程。

## Abstract
On-policy self-distillation (OPSD) lets a language model learn from a frozen copy of itself that sees an answer or a worked solution. Giving the teacher this extra information seems to offer the student more to learn, but how much does it add beyond distillation itself? To isolate that contribution, we construct AMPLE-Math, a reusable suite of 5,319 mathematical problems with six reasoning views that share the same answer, and compare each view with matched reference-free distillation. With a thinking-enabled teacher supervising direct-response rollouts, reference-free distillation accounts for much of Qwen3-1.7B's improvement under thinking-enabled evaluation, both in domain and on external benchmarks. Evidence for an additional reference benefit is modest in Qwen, strongest for a polished solution, whereas complete traces add two percentage points in SmolLM3-3B at step 50. These benefits depend on the student being trained. At the same checkpoint, replacing short direct-response rollouts with long thinking-enabled rollouts turns gains into losses in both families while the problems, references, and evaluation stay fixed. Teacher profiles and matched loss interventions in Qwen further show that changing token-level supervision can leave student behavior largely unchanged. Together, these findings suggest that OPSD can improve access to existing reasoning capabilities through parameters shared by direct-response and thinking-enabled inference. The value of a privileged reference is what it adds to this cross-mode transfer, not how much of the solution it reveals.

# 《What Does Privileged Information Add to On-Policy Self-Distillation?》论文总结

## 1. 核心问题与研究动机

- **背景**：在策略自蒸馏（On-Policy Self-Distillation, OPSD）中，一个冻结的教师副本会看到答案或完整解题过程（即"特权信息"，Privileged Information, PI），然后对学生仅凭问题生成的回答进行打分。这与"学习使用特权信息"（LUPI）的思路一脉相承：训练时可用、推理时不可用。
- **核心疑问**：给学生"更多解题过程"看似能带来更多监督信号，但**"相比蒸馏本身，参考解答究竟额外贡献了多少？"** 仅以"相对基座模型的提升"来回答该问题是不充分的，因为无参考的跨模式蒸馏本身也会带来提升。
- **关键切入点**：教师即使没有 PI，其"思考模式"与学生的"直接回答模式"之间仍存在不对称性，因此无参考的 OPSD 其实已经是一种跨模式蒸馏。论文试图把"参考解答的贡献"从"蒸馏本身的贡献"中剥离出来。
- **整体含义**：论文主张，特权参考的价值应以其**对学生跨模式迁移的净增量**来衡量，而非以其揭示了多少解题步骤来衡量。

## 2. 方法论

### 2.1 核心思想
- 构造一个**答案匹配**的监督套件，让同一道题在固定答案的前提下，仅改变推理表示的密度，从而分离"答案可用性"与"推理表示形式"两个变量。
- 用**无参考蒸馏（reference-free）**作为严格对照：教师仍是冻结的、启用思考的骨干模型，只是不给参考文本，因此初始时教师与学生分布并不完全相同（因推理模式差异），仍存在初始损失。

### 2.2 AMPLE-Math 数据集构建
- 从 OpenThoughts-114k 抽取 5,319 道数学题，每题配 **六种视图**，共享同一验证答案：
  - `Answer Only`（13 tokens，无推理体）
  - `Gist`（76）
  - `Key Points`（284）
  - `Clean Solution`（526，精炼解答，不在长度主链上）
  - `Summary`（841）
  - `Full Trace`（4,916，完整源轨迹）
- 中间视图由 Qwen3.6-35B-A3B-FP8 生成，并经同模型另一提示做"源忠实度审查"。
- 使用多模型（Qwen2.5-1.5B-Instruct、Llama-3.1-8B-Instruct、Qwen3.6-35B）做 Rasch 难度估计；用冻结基座 4 次直接回答样本划分三个成功带（0/4、1–2/4、3–4/4），等配额划分 train/dev/test = 1,536 / 192 / 384。

### 2.3 OPSD 损失
- 学生分布 $p^S_t(a)=\pi_\theta(a\mid x, y_{<t}; m_S)$，教师分布 $p^{T_v}_t(a)=\bar\pi_\theta(a\mid x, z_v(x), y_{<t}; m_T,\tau)$。
- 损失为带**逐词表项上截断（clip=0.05）**的前向 KL 平均：
  $\mathcal{L}_v(\theta;m_S)=\mathbb{E}_{x,y\sim\pi_\theta}\left[\frac{1}{|I(y)|}\sum_{t\in I(y)} D^{clip}_{KL}(p^{T_v}_t \| p^S_t)\right]$
- 仅在前 1,024 个 completion token 上计算损失（继承自原 OPSD 实现）。

### 2.4 三类教师画像诊断指标（在固定学生响应上测量）
- **正确性对齐 $C_v$**：对同一问题内正确/错误回答的教师–学生平均对数概率差 $\Delta_v(y)$ 做对比，正值表示正确回答获得更大提升。附录 D.4 给出其局部重加权解释：$\frac{d}{d\epsilon}\mathbb{E}_{\mu_{v,\epsilon}}[R]|_{\epsilon=0}=\mathrm{Cov}(R,h_v)=p_x(1-p_x)C_v(x)$。
- **纠正标记压力 $F_v$**：在 "wait / but / check / verify / reconsider" 等再思考标记上的平均概率偏移，负值表示被抑制。
- **时间性 KL 分配**：全词表 KL 在保留跨度四个等分区间中的占比。

## 3. 实验设计

- **数据集/场景**：
  - 领域内：AMPLE-Math 的 384 题测试集，每题 4 个启用思考的样本，Avg@4。
  - 外部基准：AIME 2024、AIME 2025、HMMT February 2025，共 90 题，每题 12 个样本，Avg@12。
  - 另有"原始 OPSD 数据"上的实现校验（外部评估）。
- **模型**：Qwen3-1.7B（主）、SmolLM3-3B（跨家族验证）。
- **训练配置**：LoRA（r=64, α=128），batch 32，lr 5e-6，AdamW，温度 1.1，100 步；检查点 0/1/2/5/10/15/20/25/50/75/100。主配置为**直接回答式 rollout 训练 + 思考式评估**。
- **对比方法/条件**：
  - 无参考蒸馏（reference-free）、错误答案对照（wrong answer）、六种 PI 视图。
  - 训练轨迹对比：直接回答式 rollout vs 思考式 rollout（同一损失窗口）。
  - 17 组单种子匹配干预：他题参考替换、轨迹开头截断（trace opening）、纠正标记损失排除/降权、提示模板替换、损失窗口（Early-1K / First-4K / Distributed-1K）。
- **统计方法**：问题为推断单位，10,000 次问题簇 bootstrap 重采样，Holm 多重比较校正，并区分"配对区间不含零"与"通过 Holm 校正"。

## 4. 资源与算力

- 论文在附录 A.5 中明确说明：**总项目算力约 1,000 H100 GPU-hours**，涵盖训练、评估、教师画像、数据集构建与搭建。
- 未逐项拆分各实验的 GPU 数量与时长；训练规模本身较小（LoRA + 100 步）。

## 5. 实验数量与充分性

- **规模**：
  - 六视图 × 两个模型家族 × 多个检查点（25/50/100）；Qwen 极端视图（Answer Only / Full Trace）各 4 个种子，其余多为 1–3 个种子。
  - 17 组单种子匹配干预实验。
  - 教师画像使用 512 题 × 每题 4 条无 PI 轨迹，覆盖 18,467,995 个 token 位置、129,275,965 次 token–条件评分。
- **充分性与公平性亮点**：
  - 通过"答案匹配 + 无参考对照 + 错误答案对照"三层设计，有效分离答案信息与推理表示。
  - 使用 Holm 校正、配对 bootstrap、多种子与种子级 t 区间、开发集选点（不接触测试集），统计规范较严谨。
  - 跨模型家族（Qwen3-1.7B 与 SmolLM3-3B）复现关键结论。
- **仍显不足**：
  - 多数干预实验仅单种子，效应量（约 1–2 个百分点）与噪声量级接近。
  - 主结果中"Clean Solution 相对无参考的 +1.30 分"在 Holm 校正后不显著。
  - 只在数学推理、短程 LoRA 微调、两个 1.7B/3B 级模型上验证，泛化性存疑。

## 6. 主要结论与发现

- **蒸馏收益 ≠ 参考收益**：无参考蒸馏已解释 Qwen3-1.7B 的大部分提升（领域内与外部均有正增益），甚至错误答案对照也优于基座；更完整的推理过程并未带来一致的更大收益。
- **参考的额外价值有限且依模型/阶段而异**：Qwen 中 Clean Solution 有微弱证据（+1.30 [0.20, 2.41]，但未过 Holm 校正）；SmolLM3 中 Full Trace 在第 50 步比无参考高约 2 个百分点，但在第 100 步所有配置均跌破基座，Full Trace 跌幅最小。
- **收益集中在"基座有时能解对"的题目**：0/4 直接回答成功但思考模式下约 62% 正确的问题组收益最大，支持"改善对已有能力的获取"这一共享参数解释。
- **训练轨迹决定迁移方向**：固定问题、参考与评估，仅把直接回答式 rollout 换成思考式 rollout，就在两个家族中把增益变成损失（Qwen 九组对比全部为负，八组显著；SmolLM3 第 50 步 −6.84 分）。
- **评估模式会反转排名**：直接回答式评估下，Qwen 的 Answer Only 与无参考学生反而大幅超过 Full Trace（+5.32、+10.81），SmolLM3 的 Full Trace 优势从 +2.00 变为 −10.63。
- **监督信号的改变未必改变学生行为**：放松纠正标记损失几乎不改变标记使用；扩大损失窗口带来的"约 4 分收益"在匹配检查点后降至 1 分以内（约 76% 来自提前停止/检查点选择）。
- **总结论**：OPSD 的价值在于通过直接回答与思考推理共享的参数，改善对已有推理能力的访问；特权参考的价值在于它对这种跨模式迁移的增量，而非解题过程的完整程度。

## 7. 优点

- **问题切分清晰**：明确区分"相对基座的提升"与"相对无参考蒸馏的增量"，直击 OPSD 文献中一个常被混淆的度量问题。
- **数据集设计可复用**：AMPLE-Math 的六视图答案匹配设计，为后续 PI 研究提供了可控实验床，并附带源忠实度审查、难度标注与冻结划分。
- **控制变量严谨**：错误答案对照、他题长度匹配参考、轨迹截断、模板替换等干预，逐一排除"文本长度""提示措辞""答案内容"等混杂因素。
- **诊断–干预闭环**：先用教师画像提出假设（正确性对齐、标记抑制、KL 前置），再用匹配训练实验检验，并区分"监督改变"与"学生行为改变"。
- **统计意识强**：问题簇 bootstrap、Holm 校正、种子级与问题级不确定性的分别报告，并明确指出区间含零不等于等价。
- **诚实的负面结果**：如实报告多数干预无效、参考收益不显著、以及检查点选择造成的假象。

## 8. 不足与局限

- **模型与任务覆盖面窄**：仅数学推理、两个小规模模型（1.7B/3B）、LoRA 短程训练（100 步）；结论能否推广到更大模型、更长训练、代码/开放域任务未知。
- **效应量小、种子少**：核心参考收益约 1–2 个百分点，多数干预为单种子，部分结论（如 Clean Solution 优势）经多重比较校正后不显著。
- **超参数选择依赖继承设置**：损失仅覆盖前 1,024 token（对长思考 rollout 覆盖率仅约 18.6%），使用实现代码的 β=0 与 0.05 截断而非原论文描述，可能影响可比性。
