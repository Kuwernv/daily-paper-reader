## 摘要
同策略蒸馏（OPD）已成为大语言模型后训练的一种有效方法，但现有目标面临目标保真度与优化稳定性之间的权衡。Token 级 OPD 提供稳定但局部的监督，而序列级 OPD 能够捕捉未来信用，却以依赖 horizon 的方差为代价。我们为这些形式建立统一的时序信用视角，表明实际中的 Token 级 OPD 可解释为对序列级反向 KL 梯度的一种时序近似。基于这一联系，我们提出 γOPD（GammaOPD），其使用折扣时序信用分配来平衡长时域监督与优化稳定性，同时具有与 horizon 无关的方差上界。我们进一步为 γOPD 开发一种奖励兼容的有界混合（RBM）机制，以平衡可验证的结果反馈与折扣 OPD 优势，从而超越纯教师依赖的优化。在数学和代码推理上的实验表明，在原始、规模不匹配和多教师蒸馏设置中，该方法相较现有 OPD 方法取得一致改进。

## Abstract
On-policy distillation (OPD) has emerged as an effective approach for large language model post-training, yet existing objectives face a trade-off between objective fidelity and optimization stability. Token-level OPD provides stable but local supervision, whereas sequence-level OPD captures future credit at the cost of horizon-dependent variance. We establish a unified temporal-credit view of these formulations, showing that practical token-level OPD can be interpreted as a temporal approximation to the sequence-level reverse-KL gradient. Building on this connection, we propose $γ$OPD (GammaOPD), which uses discounted temporal credit assignment to balance long-horizon supervision and optimization stability, while admitting a horizon-independent variance bound. We further develop a reward-compatible bounded mixing (RBM) mechanism for $γ$OPD that balances verifiable outcome feedback with the discounted OPD advantage to move beyond purely teacher-dependent optimization. Experiments on mathematical and code reasoning demonstrate consistent improvements over existing OPD methods across vanilla, size-mismatched, and multi-teacher distillation settings.

## 2. 方法论

### 2.1 统一时序信用视角（理论基础）

- **记号**：token 级对数比 $\Delta_t=\log\pi_\theta(y_t|h_t)-\log\pi^*(y_t|h_t)$；序列级对数比 $\Delta(y)=\sum_{t=1}^{T}\Delta_t$；token 级 OPD 优势 $A_t^{OPD}=-\Delta_t$。
- **两个目标的定义**：
  - 序列级目标 $J^{seq}_{OPD}$：在完整响应轨迹上比较学生与教师分布。
  - token 级目标 $J^{token}_{OPD}$：在各前缀处比较下一 token 分布，且前缀分布 $\bar d_{\bar\theta}(h_t|x)$ 采用 **stop-gradient**。
- **关键洞察**：当 $\bar\theta=\theta$ 时二者**函数值等价**，但**梯度不等价**——差异正来自前缀分布的 stop-gradient 处理。
- **命题 3.1（token 级梯度）**：$\nabla_\theta J^{token}_{OPD}=\mathbb{E}\big[\sum_t \Delta_t\nabla_\theta\log\pi_\theta(y_t|h_t)\big]$，恰好还原实际 OPD 更新式。
- **命题 3.2（序列级梯度）**：$\nabla_\theta J^{seq}_{OPD}=\mathbb{E}\big[\sum_t\big(\sum_{t'=t}^{T}\Delta_{t'}\big)\nabla_\theta\log\pi_\theta(y_t|h_t)\big]$。
- **结论**：实际 OPD 丢弃了 $y_t$ 对后续所有前缀的间接影响，只保留局部项 $\Delta_t$，因此是序列级反向 KL 梯度的**时序截断近似**。

### 2.2 γOPD：折扣时序信用

- **核心思想**：引入折扣因子 $\gamma\in[0,1]$ 控制未来 OPD 信用向当前 token 的分配量。
- **折扣优势**：$A_t^{(\gamma)}=-\sum_{t'=t}^{T}\gamma^{t'-t}\Delta_{t'}$。
  - $\gamma=1$：退化为序列级 return-to-go（恢复命题 3.2 的梯度）。
  - $\gamma=0$：退化为 token 级优势 $A_t^{(0)}=-\Delta_t$（恢复命题 3.1 的梯度）。
  - $0<\gamma<1$：刻意构造的**有偏代理梯度**，在两端点之间插值，并可通过 $\gamma$ 控制方差。
- **定理 3.3（方差稳定性）**：在 token 级优势二阶矩有界（$\mathbb{E}[(A_t^{(0)})^2]\le\sigma_\Delta^2$）的假设下：
  - 序列级信用：$\mathrm{Var}(A_t^{(1)})\le(T-t+1)^2\sigma_\Delta^2$，**随剩余视界二次增长**（且该界在最坏情形可达）。
  - γOPD 信用：$\mathrm{Var}(A_t^{(\gamma)})\le\sigma_\Delta^2/(1-\gamma)^2$，对任意固定 $\gamma<1$ 均为**视界无关**上界。

### 2.3 RBM：奖励兼容的有界混合

- **动机**：γOPD 的信号仍源于教师分布，学生可能受教师上限约束，缺乏任务级优化信号；但简单叠加可验证奖励会让量级不定的教师优势淹没 $\{-1,1\}$ 的有界奖励。
- **三步机制**：响应内平均绝对幅值归一化 → softsign 式有界变换 → 与可验证奖励相加：
  $$\hat A_t^{(\gamma)}=\frac{A_t^{(\gamma)}}{\frac{1}{T}\sum_k|A_k^{(\gamma)}|+|A_t^{(\gamma)}|}+R(x,y)$$
  （分母为零时定义归一化教师项为零。）
- **性质**：第一项在 $(-1,1)$ 内单调有界，保留 token 间相对信用；因 $R\in\{-1,1\}$，有 $\mathrm{sign}(\hat A_t^{(\gamma)})=R(x,y)$，即**奖励决定强化/抑制方向，折扣 OPD 信用只调节 token 级更新强度**，故称"奖励兼容"。
- **最终代理梯度**：$\hat g_\gamma(\theta)=-\mathbb{E}\big[\sum_t\hat A_t^{(\gamma)}\nabla_\theta\log\pi_\theta(y_t|h_t)\big]$；论文中 γOPD 默认指与 RBM 结合后的版本。
- **算法流程**（Algorithm 1）：采样 prompt 与响应 → 验证器给出 $R$ → 逐 token 计算 $\Delta_t$ → 按上式（式 7、8）计算 $\hat A_t^{(\gamma)}$ → 用式 9 更新参数。
