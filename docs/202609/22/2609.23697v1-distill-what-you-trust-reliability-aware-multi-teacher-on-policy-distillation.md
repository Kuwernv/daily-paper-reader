## 摘要
多教师同策略蒸馏允许学生模型在其自身轨迹上向互补的专家学习。然而，领域路由方法为每个示例选择一个教师，并在整个响应过程中保持固定。这种设计既依赖于混合训练语料库通常缺乏的标签，也无法在轨迹内所需专业知识发生变化时自适应地选择教师。我们提出 TrustMOPD，它用无标签的、词元级的监督分配取代了示例级的教师选择。在每个学生生成的前缀处，TrustMOPD 使用每个专家相对于共享的 RL 前参考的 RL 诱导位移作为局部可靠性的代理，跨教师校准这些分数，并构建加权蒸馏目标。在数学、代码和指令遵循方面，TrustMOPD 优于最强的无标签基线，在 SingleCap 上将恢复率从 54.4% 提高到 91.5%，在 MultiCap 上从 54.5% 提高到 98.0%，同时在 SingleCap 上接近基于标签的 MOPD。独立于学生生成前缀随机化词元级权重，其表现并不优于均匀加权，这支持了将监督条件化于不断演化的生成上下文的重要性。

## Abstract
Multi-teacher on-policy distillation allows a student to learn from complementary specialists on its own trajectories. Domain-routed approaches, however, select one teacher per example and keep it fixed throughout the response. This design both depends on labels that mixed training corpora often lack and cannot adapt teacher selection when the expertise required changes within a trajectory. We propose \textbf{TrustMOPD}, which replaces example-level teacher selection with label-free, token-level supervision allocation. At each student-generated prefix, TrustMOPD uses each specialist's RL-induced displacement from a shared pre-RL reference as a proxy for local reliability, calibrates these scores across teachers, and constructs a weighted distillation target. Across mathematics, code, and instruction following, TrustMOPD outperforms the strongest label-free baseline, increasing the recovery ratio from $54.4\%$ to $91.5\%$ on \textsc{SingleCap} and from $54.5\%$ to $98.0\%$ on \textsc{MultiCap}, while approaching label-based MOPD on \textsc{SingleCap}. Randomizing token-level weights independently of the student-generated prefix performs no better than uniform weighting, supporting the importance of conditioning supervision on the evolving generation context.

# TrustMOPD 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：多教师同策略蒸馏（MOPD）让学生模型在自身生成的轨迹上向多个互补专家学习，从而在统一训练过程中整合数学推理、代码生成、指令遵循等能力。
- **现有做法**：领域路由式 MOPD 在示例级别选择一位教师，并在整条响应中固定该选择（one-hot 权重）。
- **两大缺陷**：
  - **依赖标签**：混合训练语料往往缺乏唯一的领域标签，多能力提示（如“数学推导 + 代码验证 + JSON 格式”）无法被单一标签刻画。
  - **无法自适应**：一条轨迹内所需专长会随生成位置变化，固定教师无法在“推导—验证—格式化”等阶段切换监督来源。
- **更深层问题**：教师的**全局领域专长**不等于**当前状态的局部监督可靠性**；教师—学生分歧大也不一定是可靠信号，可能源于风格偏好或无关行为。
- **核心主张**：应当用**无标签、状态相关、跨教师可比**的可靠性估计，在 token 级别动态分配监督权重，而不是在示例级别固定路由。

## 2. 方法论：TrustMOPD

### 2.1 核心思想
- 所有教师由**同一个 pre-RL 参考模型**经领域特定 RL 得到。教师相对该共享参考的 **RL 位移**，可隔离出 RL 引入的专长变化。
- 在学生的每个生成状态上，若某教师的专长被激活，其 next-token 分布会明显偏离参考；反之则接近参考。因此**位移幅度**可作为局部可靠性的无标签代理。
- 位移分数经跨教师校准后，通过幂归一化转为 token 级监督权重，代入标准 MOPD 损失。

### 2.2 关键技术细节

- **状态定义**：输入 \(x\)，学生生成响应 \(y\)，位置 \(t\) 的学生状态 \(s_t=(x,y_{<t})\)；\(p_{\theta,t}\) 为学生分布，\(q_{k,t}\) 为教师 \(k\) 分布，\(q_{\text{ref},t}\) 为参考分布。
- **中心化 RL 位移**：
  - \(d_{k,t}(v)=\log\frac{q_{k,t}(v)}{q_{\text{ref},t}(v)}-\frac{1}{|V|}\sum_{v'}\log\frac{q_{k,t}(v')}{q_{\text{ref},t}(v')}\)
  - \(\rho_{k,t}=\|d_{k,t}\|_2\)
  - 中心化去掉 token 无关的加性分量，范数保留位移幅度、丢弃方向。
- **跨教师校准**：
  - 在未蒸馏学生 \(\pi_{\theta_0}\) 的校准分布上估计教师典型幅度 \(\mu_k=\mathbb{E}_{\text{cal}}[\sum_t\rho_{k,t}]/\mathbb{E}_{\text{cal}}[|y|]\)
  - 校准分数 \(r_{k,t}=\rho_{k,t}/\mu_k\)，使各教师在校准分布上均值为 1，可跨教师比较。
- **幂归一化权重**：
  - \(w_{k,t}=r_{k,t}^{\gamma}/\sum_{j=1}^{K}r_{j,t}^{\gamma}\)，\(\sum_k w_{k,t}=1\)
  - \(\gamma>0\) 控制分配集中度，越大越偏向高可靠性教师。
- **加权蒸馏目标**：
  - \(L_{\text{MOPD}}(\theta;w)=\mathbb{E}_{x\sim D,\,y\sim\pi_\theta}\left[\frac{1}{|y|}\sum_{t=1}^{|y|}\sum_{k=1}^{K}w_{k,t}D_{\text{KL}}(p_{\theta,t}\|q_{k,t})\right]\)
  - 标准 MOPD 是其特例：\(w_{k,t}=I\{k=d(x)\}\)。
- **权重性质**：权重在采样 rollout 上计算并视为常数，梯度不反传；每 token 权重和为 1，因此损失形式、总监督质量、有效更新尺度不变，只改变教师间分配。
- **理论支撑**：
  - **定理 1（效用对比恢复）**：在 KL 正则化序列生成的收敛最优策略假设下，\(d_{k,t}(v)=(Q^\star_k(s_t,v)-\bar Q^\star_{k,t})/\beta_k\)，位移精确恢复可识别的动作相关效用对比。
  - **推论 1（相对效用分配）**：校准后 \(r_{k,t}=\sigma_{k,t}/\bar\sigma_k\)，权重倾向于“相对自身基线效用对比最大”的专家，而非绝对尺度最大者。

## 3. 实验设计

### 3.1 模型与训练设置
- 全部模型基于 **SmolLM3-3B** 架构。
- 混合域 SFT checkpoint 同时作为学生初始化 \(\pi_{\theta_0}\) 与共享 pre-RL 参考 \(\pi_{\text{ref}}\)。
- 通过领域特定 RL 得到 **K=3 个教师**：数学、代码、指令遵循。

### 3.2 数据集 / 场景
- 两个训练集各 **7,458 prompts**，均排除评测数据：
  - **SingleCap**：来自 OpenMOPD，含 1,540 数学、1,870 代码、4,048 指令遵循，每例有唯一领域标签。
  - **MultiCap**：仿 MathIF，为数学和代码问题添加可程序验证的指令约束，并保留独立 IF 样本以匹配 OpenMOPD 域比例；多数样本跨两种能力，**无唯一领域标签**。

### 3.3 Benchmark

- 生成设置：数学 16 次/例、温度 0.6；代码 5 次/例、温度 1.0；IF 1 次/例、温度 1.0。

### 3.4 对比方法

## 6. 主要结论与发现

- **总体效果**：TrustMOPD 在两种设置下均为最强无标签蒸馏方法。
  - SingleCap：Overall **30.04 ± 0.47**，比初始化 +5.15，仅比标签路由 MOPD（30.18 ± 0.25）低 0.14。
  - MultiCap：Overall **30.41 ± 0.60**，超过最强无标签基线 Random 2.45 分。
- **恢复率**：SingleCap 从 54.4% 提升到 **91.5%**；MultiCap 从 54.5% 提升到 **98.0%**。
- **分配与专长对齐**：
  - SingleCap 上数学/代码/IF 教师在其对应域的平均权重为 **0.69 / 0.65 / 0.99**；correct-teacher margin 为正的 rollout 比例为 **98% / 91% / 100%**。
  - MultiCap 上相关教师联合获得 0.89 / 0.75 / 0.73 的权重；数学+IF 提示中数学与 IF 教师分别得 0.51 和 0.38，无关代码教师仅 0.11。
  - token 级案例显示：数学教师在操作数与算术处权重高，得到结果后 IF 教师主导解释与 `\boxed{}` 格式化。
- **随机权重无效**：独立于学生前缀随机化 token 权重，表现不比均匀加权好，说明**条件化于演化生成上下文**是关键。
- **消融结论**：RL 位移优于置信度、负熵、师生 KL；校准与 token 级分配在 MultiCap 上贡献更大（去掉 \(\mu_k\) 掉 1.28 分，response-level 掉 0.92 分；SingleCap 仅 0.31 / 0.05）。
- **\(\gamma\) 敏感性**：SingleCap 上增益稳定在 5.11–5.40；MultiCap 上 \(\gamma=7\) 最佳（5.52），\(\gamma=9\) 降至 4.87，说明过度集中会放大 \(\rho_{k,t}\) 误差并压制互补教师。
- **迁移性**：换 7B backbone 后增益 7.49 / 6.30；换独立数据源后仍有 4.58 / 4.30，且超过在 OpenMOPD 上训练的最强竞争基线。
