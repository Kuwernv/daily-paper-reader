## 摘要
多组学序列包含复杂的生物模式，然而破译其机制以实现自动化科学发现仍然具有挑战性。当大语言模型（LLM）解释这些序列时，评估其预测与科学推理都至关重要。然而，现有多组学序列任务基准依赖分类和回归指标，忽视了模型是否掌握潜在的生物学证据。我们提出 OmicsBench，这是首个面向多组学序列的推理基准，包含 1,160 个经专家验证的问题，涵盖 DNA 调控、RNA 加工和蛋白质功能等六项任务。OmicsBench 要求可追溯的证据链，并使用与领域专家共同开发的实例特定评分细则进行评估。对 17 个 LLM 的评估揭示了一种反向关系：科学 LLM 在序列分类准确率上优于通用 LLM，却无法提供有效证据来支持其预测。一种合理解释是捷径学习：专用模型可能依赖统计模式，而非科学发现所需的生物学机制。受此发现启发，我们提出工具增强同策略蒸馏（TA-OPD），一种后训练方法，用于使序列预测与基于证据的生物学推理对齐。在五个参数规模从 0.8B 到 27B 的 Qwen3.5 模型上，TA-OPD 持续增强生物证据依据，同时在大多数任务上提升预测性能。这些增益在不同模型规模上均存在，表明更强的序列推理并非仅来自模型容量增加，而是可以通过证据感知训练得到提升。OmicsBench 与 TA-OPD 共同提供了一个框架，用于诊断多组学 LLM 中的推理失败，并指向一条通向其预测更好建立在有生物学意义证据之上的模型的路径。

## Abstract
Multi-omics sequences contain complex biological patterns, yet deciphering their mechanisms for automated scientific discovery remains challenging. As large language models (LLMs) interpret these sequences, evaluating both predictions and scientific reasoning is critical. However, existing benchmarks for multi-omics sequence tasks rely on classification and regression metrics, neglecting whether models grasp the underlying biological evidence. We introduce OmicsBench, the first reasoning benchmark for multi-omics sequences, comprising 1,160 expert-validated questions across six tasks spanning DNA regulation, RNA processing, and protein function. OmicsBench requires traceable evidence chains, evaluated using instance-specific rubrics developed with domain experts. Evaluating 17 LLMs reveals an inverse relationship: while scientific LLMs outperform general-purpose LLMs in sequence classification accuracy, they fail to provide valid evidence to support their predictions. One plausible interpretation is shortcut learning: specialized models may rely on statistical patterns rather than the biological mechanisms needed for scientific discovery. Motivated by this finding, we introduce tool-augmented on-policy distillation (TA-OPD), a post-training method to align sequence prediction with evidence-grounded biological reasoning. Across five Qwen3.5 models spanning 0.8B to 27B parameters, TA-OPD consistently strengthens biological evidence grounding while improving predictive performance on most tasks. These gains persist across model scales, indicating that stronger sequence reasoning does not arise solely from increased model capacity, but can be improved through evidence-aware training. Together, OmicsBench and TA-OPD provide a framework for diagnosing reasoning failures in multi-omics LLMs and a path toward models whose predictions are better grounded in biologically meaningful evidence.

## 2. 方法论

### 2.1 OmicsBench 基准构建

- **生物学对齐设计**：按中心法则组织为三大类、六项任务：
  - DNA 调控：表观遗传标记预测（EMP, MCC）、启动子检测（Prom, MCC）、转录因子结合位点预测（TFBS, MCC）
  - RNA 加工：RNA 修饰预测（Mod, AUC）、非编码 RNA 分类（ncRNA, Acc）
  - 蛋白质功能：酶功能预测（EC, Fmax）
- **数据过滤**：源自 Biology-Instructions 的 34,033 条测试样本；先用余弦相似度 + 核心集选择（coreset selection）保留代表性序列，再做分层采样平衡标签，得到 5,537 条候选。
- **多智能体合成（agentic synthesis）**：基于 Biomni 框架，Bio-Agent（Claude-Sonnet-4.5）调用 BLAST、ViennaRNA、JASPAR、PubMed API 等工具生成推理链；Verifier Agent 做双重校验——① 标签一致性（预测与原始标签不符则丢弃），② 逻辑连贯性（工具输出是否逻辑支持结论）。约 1,512 题通过。
- **专家验证**：3 位领域专家独立评审（科学准确性、证据相关性、推理完整性），多数接受才保留，最终得 1,160 题。

### 2.2 评测框架：Rubric Recall（RR）

- **分层评分细则结构**：
  - 任务级维度 $D_{task}$：专家为每类任务定义通用评估维度（如 EC 的同源证据、活性位点基序、催化残基、底物特异性、反应化学）。
  - 实例级细则 $R_q = \{r_1, ..., r_k\}$，每条 $r=(d, E)$，$d$ 为维度，$E$ 为从标准答案中抽取的原子证据单元集合。
- **构建流程**："Define–Decompose–Scale–Verify"：专家定义维度 → 每任务标注 5 题做原子化分解示范 → Summarizer Agent 用 in-context learning 扩展到全部题目 → 专家复核去冗余与纠错。最终 1,160 题共 **3,745 个评分维度（约 3.2 个/题）**，由 **11,392 条具体证据项**支撑（约 3.0 条/维度）。
- **RR 公式**：$RR(q) = \frac{1}{|R_q|}\sum_{r \in R_q} \mathbb{1}(r \text{ is satisfied by } \hat{y}_q)$，其中一条细则只要其任一原子证据被模型回答覆盖即算满足。
- **LLM 评判协议**：三条判定标准——① 精确实体匹配（如 PDB ID）、② 语义等价（容忍表述差异）、③ 上下文有效性（证据须真正支持结论，而非误引或幻觉）；并校验定量约束（如"78% 相似度"满足"≥75%"阈值）。
- **抗刷分设计**：按推理维度数而非原始证据数取平均，堆砌文本无法抬分；模板式关键词注入响应（约 1,000 token）在六项任务上得分均低于 1.2%。

### 2.3 TA-OPD（工具增强同策略蒸馏）

- **核心思想**：把"工具型生物医学 Agent 的答案 + 支撑证据"作为**特权信息（privileged information）**，仅提供给教师模型，学生模型在推理时不用工具。
- **技术谱系**：
  - OPD：由更强的外部教师逐 token 指导学生。
  - OPSD：教师与学生由同一模型初始化，仅教师可见 ground-truth 答案。
  - **TA-OPD**：沿用 OPSD 的同源初始化，但特权信息改为工具型 Agent（Biomni）分析同一序列后给出的答案与生物学证据。
- **训练流程（文字化算法）**：
  1. 教师与学生从同一模型权重初始化，**教师全程冻结**，仅更新学生。
  2. 学生仅接收任务指令与生物序列，自行生成完整回答（含解释与最终预测）。
  3. 教师在同一学生生成序列上计算逐 token 概率，但额外看到 Agent 的答案与证据。
  4. 蒸馏信号 = 教师 log 概率 − 学生 log 概率，逐 token 回传，学生据此更新。
  5. **答案—标签一致性门控**：仅当 Agent 最终预测与真值标签一致时，该样本才进入训练。
- **降低"特权幻觉"（privilege illusion）**：教师所见证据来自对同一序列同一问题的工具分析（BLAST 输出、数据库记录），与输入强关联，学生可学习"预测背后的生物学前提与分析路径"，而非单纯模仿结果。
- **训练超参**：采样 token 的 $k_1$ log-ratio 估计器 + 策略梯度优化 + AdamW；3% warm-up 后恒定学习率 $2\times10^{-6}$，权重衰减 0.01；prompt 上限 8,192 token，响应上限 16,384 token。

## 6. 主要结论与发现

- **推理退化现象**：科学 LLM 在常规指标上最强（每列最佳单项成绩均由科学 LLM 取得，如 ChatNT 在 EMP 达 86.86% MCC，SciReasoner 在 EC 达 77.41% Fmax，Avg Rank 最优者为 ChatNT 3.00 / Intern-S1-Pro 3.50），但 RR 普遍极低（ChatNT 在 EMP 的 RR 为 0%）。通用 LLM 则相反：Avg Recall 最高为 Grok-4（21.10%）、Qwen3-Max（18.53%）、Gemini-3-Pro（16.17%），且在全部六项任务上取得最高 RR。
- **相关性反转**：通用模型族内预测与推理呈中等正相关（$r=0.26$），科学模型族内转为负相关（$r=-0.29$）。科学模型预测分数约为通用模型的 1.5 倍（12.11 vs 7.94），但推理质量仅约 0.2 倍（3.01% vs 13.76%）。
- **输出长度证据**：科学 LLM 平均仅生成 47 token，通用 LLM 为 857 token，支持"短标签生成而非证据推理"的捷径学习解释。
- **能力不均衡**：DNA 调控与 Mod 的 RR 峰值较高（Prom 30.16%、TFBS 27.46%、Mod 29.95%），蛋白质任务 EC 的 RR 最低（最高仅 13.34%）；无任何模型在六项 RR 中均进入前三，也无模型在常规指标上跨模态一致占优。
- **三类失败模式**：① 弱信号确定性放大（把 GC 富集区、短基序当作功能确证）；② 生物学状态幻觉（无证据却断言"开放染色质""甲基化"）；③ 虚构工具结果（如声称"BLAST 显示高同源性"但实际无工具访问）。
- **TA-OPD 效果**：
  - 预测性能：0.8B 改善 4/6 任务，2B 与 4B 各 5/6，9B 与 27B 均 6/6。Prom 的 MCC 在 2B/4B/9B/27B 分别提升 15.94 / 20.50 / 34.97 / 33.13 个百分点；EMP 在 9B 提升 +28.89、27B 提升 +34.04；ncRNA 准确率在五个规模上全部提升，27B 从 5.12% 升至 19.22%。Mod 的 AUC 变化很小，
