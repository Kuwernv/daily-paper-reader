## 摘要
在策略自蒸馏（OPSD）使语言模型能够从一个冻结的自身副本中学习，该副本可以看到答案或解题过程。将这种额外信息给予教师似乎能为学生提供更多可学习的内容，但除了蒸馏本身之外，它究竟带来了多少增益？为了分离这一贡献，我们构建了 AMPLE-Math，一个可复用的套件，包含 5,319 道数学题，每道题有六种推理视图且共享同一答案，并将每种视图与匹配的无参考蒸馏进行比较。在由启用思考的教师监督直接回答式 rollout 时，无参考蒸馏解释了 Qwen3-1.7B 在启用思考的评估下的大部分提升，无论是在领域内还是在外部基准上。在 Qwen 中，额外参考增益的证据较为有限，对于精炼解答最强；而在 SmolLM3-3B 中，完整轨迹在第 50 步带来了两个百分点的提升。这些增益取决于所训练的学生模型。在同一检查点，将短直接回答式 rollout 替换为长思考式 rollout，会在两个模型系列中把增益变为损失，而题目、参考和评估保持不变。在 Qwen 中，教师画像和匹配的损失干预进一步表明，改变 token 级监督可能使学生行为基本保持不变。总之，这些发现表明，OPSD 可以通过直接回答式推理和思考式推理共享的参数，改善对现有推理能力的获取。特权参考的价值在于它能为这种跨模式迁移增加什么，而不在于它揭示了多少解答内容。

## Abstract
On-policy self-distillation (OPSD) lets a language model learn from a frozen copy of itself that sees an answer or a worked solution. Giving the teacher this extra information seems to offer the student more to learn, but how much does it add beyond distillation itself? To isolate that contribution, we construct AMPLE-Math, a reusable suite of 5,319 mathematical problems with six reasoning views that share the same answer, and compare each view with matched reference-free distillation. With a thinking-enabled teacher supervising direct-response rollouts, reference-free distillation accounts for much of Qwen3-1.7B's improvement under thinking-enabled evaluation, both in domain and on external benchmarks. Evidence for an additional reference benefit is modest in Qwen, strongest for a polished solution, whereas complete traces add two percentage points in SmolLM3-3B at step 50. These benefits depend on the student being trained. At the same checkpoint, replacing short direct-response rollouts with long thinking-enabled rollouts turns gains into losses in both families while the problems, references, and evaluation stay fixed. Teacher profiles and matched loss interventions in Qwen further show that changing token-level supervision can leave student behavior largely unchanged. Together, these findings suggest that OPSD can improve access to existing reasoning capabilities through parameters shared by direct-response and thinking-enabled inference. The value of a privileged reference is what it adds to this cross-mode transfer, not how much of the solution it reveals.

## 1. 核心问题与整体含义

- **研究动机**：在策略自蒸馏（On-Policy Self-Distillation, OPSD）中，教师是学生模型的一个冻结副本，但被额外给予答案或完整解题过程（即"特权信息"）。直觉上，教师看到越完整的解答，学生似乎越能学到东西——但这一直觉缺乏对照检验。
- **核心问题**：相对于"无参考蒸馏"（reference-free distillation）本身带来的提升，特权参考（reference）究竟额外贡献了多少？换句话说，把"参考内容的价值"与"蒸馏过程本身的价值"分离开来。
- **背景张力**：已有并发研究发现，即使没有目标题目的参考、甚至用其他题目的参考也能获得有效监督；结构化指导有时优于完整解答。因此"相比基座模型的提升"并不能回答参考贡献这一问题。
- **整体含义**：论文主张应当以"参考为学生增加了什么"来评判特权信息，而非"参考向教师揭示了多少解答"。OPSD 的价值可能主要在于通过**直接回答模式与思考模式共享的参数**，改善对模型已有推理能力的调用（跨模式迁移）。

## 2. 方法论

### 2.1 核心思想：答案匹配的受控比较

- 构建 **AMPLE-Math**（Answer-Matched Privileged Levels of Explanation）：从 OpenThoughts-114k 筛选出 **5,319 道数学题**，每题配备**六种推理视图**，全部共享同一经校验的答案，仅推理表示的密度不同：
  - **Answer Only**（无推理主体，13 tokens）
  - **Gist**（中心方法，76 tokens）
  - **Key Points**（有序步骤，284 tokens）
  - **Clean Solution**（精炼解答，526 tokens）
  - **Summary**（叙述性总结，841 tokens）
  - **Full Trace**（完整源轨迹，4,916 tokens）
- 另设**无参考对照（Reference-free，0 token）**与**错误答案对照（Wrong answer，用其他题目的答案）**，从而在保持答案信息固定的前提下，分离推理表示形式的影响。

### 2.2 OPSD 训练目标

- 学生 $\pi_\theta$ 只看题目 $x$ 生成 rollout $y$；冻结的、启用思考的教师 $\bar\pi_\theta$ 看到 $(x, z_v(x), y_{<t})$ 并对同一前缀打分。
- 损失为**教师到学生的前向 KL**，对词表中每一项做 0.05 的逐项裁剪后求和，在监督位置 $I(y)$ 上平均：
  $$\mathcal{L}_v(\theta; m_S) = \mathbb{E}_{x,\, y\sim\pi_\theta}\Big[\tfrac{1}{|I(y)|}\sum_{t\in I(y)} D^{\text{clip}}_{KL}(p^T_{v,t} \| p^S_t)\Big]$$
- **关键点**：无参考对照中，教师仍为"思考模式"，学生 rollout 为"直接回答模式"，因此即使去掉参考，仍保留**跨模式不对称**——所以无参考对照本质上仍是跨模式自蒸馏。

### 2.3 诊断指标（特权画像）

- **正确性对齐 $C_v$**：在同一问题内，对比正确与错误回答的平均师生对数概率位移之差；正值表示正确答案获得更有利的位移。论文还给出其局部重加权解释（$\frac{d}{d\epsilon}\mathbb{E}[R] = p_x(1-p_x)C_v(x)$）。
- **纠错标记压力 $F_v$**：在采样的"重新考虑"标记（wait、but、check 等）上的平均位移，负值表示降低标记概率。
- **时序 KL 分配**：把全词表 KL 按保留跨度的四等分统计份额。
- 这些指标在**固定的学生回答**上计算，从而可比不同参考对同一前缀的监督方式。

### 2.4 数据构建与划分

- 视图由 Qwen3.6-35B-A3B-FP8 从完整源轨迹压缩生成，并做表面校验与源忠实度复核；长度满足 Answer Only < Gist < Key Points < Summary < Full Trace。
- 用 8–16 次多模型采样 + **二项 Rasch 模型**估计题目难度；用 Qwen3-1.7B 的四次直接回答结果划分三个成功带（3–4 对、1–2 对、0 对）。
- 训练/开发/测试集为 **1,536 / 192 / 384**；SmolLM3 使用相同开发与测试题，但训练集按其自身结果重建。

## 3. 实验设计

- **模型与训练**：Qwen3-1.7B（LoRA, r=64, α=128, 100 优化步）为主实验；SmolLM3-3B 作为跨家族验证。教师恒为冻结的思考模式骨干。
- **主评估配置**：直接回答式训练 + 思考模式评估（4 样本/题，Avg@4）；次级评估用直接回答模式。
- **Benchmark**：
  - 领域内：384 题测试集（16,384 token 预算，截断则同种子重生成）。
  - 外部：**AIME 2024、AIME 2025、HMMT February 2025**（每题 12 个思考模式样本，Avg@12）。
  - 另在原始 OPSD 训练数据上做实现校验。
- **对比方法**：六种视图 vs. 无参考对照 vs. 错误答案对照；训练轨迹对比（直接回答 rollout vs. 思考式 rollout）；17 组单种子干预实验（其他题目参考、轨迹开头截断、提示模板替换、纠错标记损失排除/降权、损失窗口 Early-1K / First-4K / Distributed-1K）。
- **统计**：以问题为推断单元，10,000 次问题簇 bootstrap；对六视图族、干预族等施加 **Holm 多重比较校正**；并报告种子级 t 区间。

- **规模**：两个模型家族 × 六视图 + 两个对照 × 多个检查点（25/50/100）；主对比使用 3–4 个训练种子；外部基准每个 30 题；画像在 512 题、每条件约 1.29 亿次 token–条件评分上进行。

- **充分性与公平性**：
  - 优点：答案匹配的六视图设计有效控制了答案信息；检查点匹配（同一步比较）避免把"早停"误判为方法收益；配对 bootstrap + Holm 校正较严谨。

## 6. 主要结论与发现

1. **大部分提升来自无参考蒸馏**：Qwen3-1.7B 在思考模式评估下的领域内与外部提升，主要由跨模式自蒸馏本身解释；甚至错误答案对照也优于基座。
2. **额外参考收益有限且依视图/模型而异**：Qwen 中 Clean Solution 有未校正的 +1.30 点优势，但未通过 Holm 校正；SmolLM3-3B 中 Full Trace 在第 50 步比无参考训练高约 **2.0 个百分点**，并在第 100 步衰减得更慢。
3. **更多推理 ≠ 更多收益**：Answer Only 与 Full Trace 在 Qwen 第 100 步仅高出无参考约 0.6 点，区间含零。
4. **训练轨迹可反转迁移方向**：在同一检查点、同一参考与评估下，把短直接回答 rollout 换成长思考式 rollout，两个家族中增益均变为损失（Qwen 九组配对差值全为负，八组显著；SmolLM3 Full Trace 第 50 步为 −6.84 点）。
5. **评估模式与参考排序不一致**：Qwen 第 100 步直接回答评估下 Answer Only 与无参考学生反超 Full Trace 5.32 / 10.81 点；SmolLM3 第 50 步 Full Trace 优势从 +2.00 变为 −10.63。
6. **收益集中在"基座本已偶尔能解"的题目**：0/4 直接回答成功但思考模式正确率 61.91% 的组别收益最大，符合"共享参数改善已有能力调用"的解释。
7. **监督信号改变未必改变学生行为**：放宽纠错标记损失几乎不改变标记使用；所谓"更广损失覆盖"的收益主要来自**停止时机**——匹配检查点后，First-4K / Distributed-1K 相对 Early-1K 的优势降至 1 点以内且区间含零。

## 7. 优点

- **控制变量设计精巧**：答案匹配的六视图 + 无参考/错误答案双对照，使"参考内容"与"蒸馏过程"可分离。
- **可复用资源**：AMPLE-Math（5,319 题 × 6 视图 = 31,914 条监督记录）附带审计、难度标注与冻结划分，便于后续研究。
- **诊断与干预结合**：教师画像（正确性对齐、标记压力、KL 时序）先提出假设，再用匹配训练实验检验，避免仅凭相关性下结论。
- **统计严谨**：问题簇 bootstrap、Holm 校正、种子级与问题级不确定性并列报告；对"区间含零"的表述克制。
- **结论具反思性**：明确指出"检查点选择"是许多表面收益的来源，并给出理论示例说明相同对齐/相同平均 KL 可导致相反的参数更新与迁移方向。

## 8. 不足与局限

- **规模与范围**：仅在两个模型家族、短程 LoRA、数学推理任务上验证；结论能否推广到更大模型、其他领域、全参数微调尚不明确。
- **实验强度不均**：17 组干预中多数为单种子；六视图对比中四视图仅单种子，参考收益的统计证据偏弱。
- **画像依赖词法规则**：纠错标记通过小写化后的子串匹配识别，仅覆盖采样标记 token，并非全部语义上的"重新考虑"。
- **数据重叠**：原始数据校验中，384 道领域内测试题有 52.6% 也出现在已发布的 OPSD 训练数据中（该检查仅用外部基准评估，但仍是潜在偏倚来源）。
