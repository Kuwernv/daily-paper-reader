## 摘要
扩散语言模型（dLLMs）通过并行生成多个 token 有望实现快速推理，但当并行解码过于激进时会遭受严重的性能下降。我们提出时间自蒸馏（TSD），一种简单的同策略方法，通过跨时间蒸馏预测来训练 dLLMs 以实现快速推理。具体而言，TSD 将模型在较早时间步的去噪分布蒸馏到其在某个 token 被确定时的最终时间步的分布。这鼓励较早的预测更好地预判模型的最终输出，从而实现激进得多的并行解码。由于教师信号来自模型自身，TSD 无需离线教师生成，并可无缝适用于基础策略和后训练策略。在数学、规划和代码领域的七个基准上，TSD 显著地将速度-质量前沿推向低计算量区域。因此，TSD 提供了一种简单、单阶段的方法来加速 dLLMs，其加速效果可与离线蒸馏相媲美，同时避免了复杂的两阶段流程。

## Abstract
Diffusion language models (dLLMs) promise fast inference by generating multiple tokens in parallel, but suffer severe performance degradation when parallel decoding is pushed too aggressively. We introduce Temporal Self-Distillation (TSD), a simple on-policy method that trains dLLMs for fast inference by distilling predictions across time. Specifically, TSD distills the model's denoising distribution at earlier timesteps toward its distribution at the final timestep at which a token is committed. This encourages earlier predictions to better anticipate the model's eventual output, enabling much more aggressive parallel decoding. Because its teacher signal comes from the model itself, TSD requires no offline teacher generation and applies seamlessly to both base and post-trained policies. Across seven benchmarks in mathematics, planning, and code, TSD substantially shifts the speed--quality frontier toward the low-compute regime. TSD thus provides a simple, single-stage approach to accelerating dLLMs, achieving speedups competitive with offline distillation while avoiding a complex two-stage pipeline.

## 1. 核心问题与整体含义
- **研究背景**：扩散语言模型（dLLMs，尤其掩码扩散模型）可通过并行提交多个 token 来加速推理，但并行解码越激进，生成质量下降越严重，形成明显的速度—质量权衡。
- **核心问题**：如何在严格限制推理步数/NFE（前向传播次数）的低计算区间，提高 dLLM 的生成质量，使激进并行解码更可靠。
- **现有方法局限**：
  - 自适应解码调度依赖模型早期预测的置信度/熵等，但受限于早期时间步本身预测不准。
  - 离线蒸馏通常需要先生成大量教师轨迹，再训练学生，属于复杂两阶段流程，且与学生自身 evolving 行为解耦。
- **论文含义**：提出 Temporal Self-Distillation（TSD），一种单阶段、on-policy 的跨时间自蒸馏方法。教师信号来自模型自身在 token 提交时刻的预测，无需离线教师数据或独立教师模型，可同时适用于基础模型和 RL 后训练模型。

## 2. 方法论
- **核心思想**：沿一条 on-policy 去噪轨迹，将模型在较早时间步对某个仍被 mask 的位置的预测分布，蒸馏到该位置最终被提交时刻的预测分布。后者条件于更完整的上下文，因此可作为更可靠的“未来自我”目标，让早期预测更接近最终输出。
- **关键设定**：
  - 使用 Fast-dLLM 风格的 unmasking-only 解码，每个位置 \(\ell\) 有唯一提交时间 \(t_\ell\)。
  - 学生分布：早期时间步 \(\hat t\) 的预测 \(p_\theta(\cdot \mid c, x^{\hat t})_\ell\)。
  - 教师分布：该位置提交时刻 \(t_\ell\) 的预测 \(p_\theta(\cdot \mid c, x^{t_\ell})_\ell\)，并做 stop-gradient。
- **目标函数**：
  - 对 prompt 和 on-policy 轨迹求期望，对每个时间步、每个 mask 位置，用散度 \(D\) 匹配早期学生分布与 stop-gradient 的提交时刻教师分布。
  - 轨迹整体用 verifier 权重 \(V(x^0)\) 加权，避免低质量轨迹强化自身错误预测。
  - 散度可选 KL 或 Jensen–Shannon；主实验用 JSD，\(\beta=0.5\)。论文指出 KL 非对称且无界，易不稳定，JSD 有界更稳定。
- **单时间步蒙特卡洛近似**：
  - 原始目标若对所有时间步求梯度开销大。
  - TSD 对每条轨迹均匀采样一个时间步 \(\hat t \sim \mathrm{Unif}\{1,\dots,T_c\}\)，只在该时间步对仍 masked 的位置计算蒸馏损失。
  - 这是对时间步平均目标的 unbiased Monte Carlo 估计，显著降低训练开销。
- **Verifier 与长度感知加权**：
  - \(V(x^0)\) 根据最终生成结果给轨迹打分，正确/高质量轨迹权重更高。
  - 长度感知权重 \(V_{\text{len}}\)：若 rollout 长度不超过目标长度 \(L_{\text{target}}\)，保留完整权重；超过则线性衰减，\(\gamma_{\text{len}}\) 控制对过长正确解的惩罚。用于代码和数学任务，避免模型为填满 canvas 生成冗长正确解。
- **算法流程**：
  1. 采样 prompt；
  2. 用当前模型和 Fast-dLLM 采样一条 on-policy 去噪轨迹，记录每个位置的提交时间；
  3. 均匀采样一个时间步 \(\hat t\)；
  4. 找到该时间步仍 masked 的位置；
  5. 计算这些位置早期预测与 stop-gradient 提交时刻预测之间的散度，并按 verifier/长度权重加权；
  6. 用梯度更新模型。
- **实现细节**：使用 LoRA 微调，rank=64、\(\alpha\)=32、dropout=0.05，适配 q/k/v/up projections，约 83.9M 可训练参数，占基座模型 1.05%。
