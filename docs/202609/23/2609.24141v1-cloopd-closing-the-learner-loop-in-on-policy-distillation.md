## 摘要
在线策略蒸馏（OPD）为每个新批次付出双重代价：学生生成轨迹，更强的教师对其评分。现有方法改进了哪些轨迹会被评分以及教师信号如何构建，但通常仅以一次 actor 更新来消费该信号。我们提出 CLOOPD，一个将教师信号获取与学生侧实现分离的闭环框架。CLOOPD 在 KL 包络内选择一个自适应 $α$ 路径点，冻结已评分的批次及其优势值，在每次 actor 传递后重新前向传播学生模型，度量实现程度，并在单独的 token 预算下分配 actor 工作量。该框架包含确定性的两遍和三遍策略、按 token 计价的 CLOOPD-TPMR，以及预算匹配的对照。在 8-H20 节点上进行的六次 300 步运行中，每个 CLOOPD 策略都在可比的教师 token 规模下提升了单遍 TOP-D 锚点：宏准确率从 15.41 提升至 CLOOPD-Fixed2 的 17.78 和 CLOOPD-Fixed3 的 19.36。在第 100 步，CLOOPD-Fixed3 达到 15.35，几乎匹配第 300 步的 TOP-D，同时使用的教师评分 token 少 67.2%，GPU 小时少 28.0%。早先在 8-A100 上的消融实验表明，自适应 $α$ 消除了观察到的信任包络违背；第三次传递增加了余量。这些结果将 CLOOPD 定位为一个框架，用于对学生从教师评分 token 中学习的充分程度进行预算分配。

## Abstract
On-policy distillation (OPD) pays twice for each fresh batch: the student generates trajectories and a stronger teacher scores them. Existing methods improve which trajectories are scored and how the teacher signal is constructed, but usually consume it with one actor update. We introduce CLOOPD, a closed-loop framework separating teacher-signal acquisition from student-side realization. CLOOPD selects an adaptive $α$ waypoint inside a KL envelope, freezes the scored batch and its advantages, re-forwards the student after each actor pass, measures realization, and allocates actor work under a separate token budget. The framework includes deterministic two- and three-pass policies, token-priced CLOOPD-TPMR, and a budget-matched control. Across six 300-step runs on an 8-H20 node, every CLOOPD policy improves the one-pass TOP-D anchor at comparable teacher-token scale: macro accuracy rises from 15.41 to 17.78 with CLOOPD-Fixed2 and 19.36 with CLOOPD-Fixed3. At step 100, CLOOPD-Fixed3 reaches 15.35, nearly matching TOP-D at step 300 while using 67.2% fewer teacher-scored tokens and 28.0% fewer GPU-hours. Earlier 8-A100 ablations show adaptive $α$ eliminates observed trust-envelope violations; a third pass adds headroom. These results position CLOOPD as a framework for budgeting how fully students learn from teacher-scored tokens.

## 一、核心问题与研究动机

- **在线策略蒸馏（OPD）的双重代价**：每个新批次中学生需生成轨迹，教师需对每个有效响应 token 打分，因此一个"教师已评分批次"是一种昂贵的学习资产，而非普通 mini-batch。
- **现有工作的偏向**：TOP-D（构造近端教师路径点）、TrOPD（定位可靠监督区域）、行为混合（信任域内修改早期 rollout 策略）等方法都在改进"**信号获取侧**"——即哪些轨迹被评分、教师信号如何构造更安全。
- **被忽视的互补问题**：在为一个安全批次付费之后，**学生在丢弃该批次前究竟多完整地实现了这一信号**？标准做法仅做一次 actor 更新，把"再买一批"（增加教师信号**广度**）和"复用已购批次多做一次 actor pass"（增加**实现深度**）混为一谈。
- **两种资源成本不同**：广度需要新的 rollout 生成与教师打分；深度只复用响应、教师 log 概率与优势，仅消耗 actor 计算，**不产生新的教师调用**。仅靠聚合步数/token/GPU 小时无法揭示学习预算花在哪。
- **整体含义**：CLOOPD 将"学生从教师打分 token 中学到多充分"提升为一个**可观测、可预算的显式设计空间**。

## 二、方法论：Probe–Observe–Allocate 闭环

### 2.1 自适应 α 路径点构造（目标可行性）

- 对提示 $x$，$y=(y_1,\dots,y_L)$ 采样自行为策略 $\pi_0$，记 $\ell^S_t=\log\pi_0(y_t|x,y_{<t})$，$\ell^T_t=\log q_T(y_t|x,y_{<t})$。
- 原始 OPD 使用采样 token log-ratio：$r^{\text{OPD}}_t=\ell^T_t-\ell^S_t$。
- TOP-D 构造近端路径点 $q_\alpha=(1-\alpha)\pi_0+\alpha q_T$，其采样 token 奖励为
  $g_{\alpha,t}=\log\left(1-\alpha+\alpha e^{\ell^T_t-\ell^S_t}\right)$，当 $\alpha<1$ 时下界为 $\log(1-\alpha)$。
- **CLOOPD 在 32 点对数网格 $\alpha\in[0.01,1]$ 上选择满足以下约束的最大 α**：
  - 采样 K3 信任代理 $\hat K_{\text{ext}}(\alpha)=\langle e^{g_\alpha}-1-g_\alpha\rangle_m\le 0.02$；
  - 下尾保护 $Q_{0.05}(g_\alpha)\ge -0.5$。
- **关键区别**：自适应 α 是**目标构造机制**，不是学习率调度。它让简单批次更靠近教师，让大间隔批次留在同一外部 K3 与奖励下尾包络内，使信任包络成为所有深度/分配策略共享的不变量。
- 将 $g_\alpha$ 转为 TOP-D token 回报
  $R_t=g_{\alpha,t}+\frac{\sum_{j=t+1}^{L}g_{\alpha,j}}{\max(L-t,1)}$，
  并在 prompt 内归一化得到 $A_0$。**路径点、响应、行为/教师 log 概率、mask、$A_0$ 在整个 transaction 生命周期内冻结。**

### 2.2 Probe：冻结信号的 actor passes

- 第 1 次 pass（E1）产生 $\pi_1$；可选 E2、E3 分别产生 $\pi_2,\pi_3$，**复用同一 $A_0$**。
- E2/E3 只消耗 actor 响应 token，**不触发 rollout 生成，也不调用教师**。
- 与通用 PPO 多 epoch 的区别：被复用的对象包含昂贵教师评估，目标是冻结的教师诱导路径点，且进展被**可观测地度量**。

### 2.3 Observe：路径点与优势实现度

- 采样 token 学生位移 $\Delta^{(k)}_t=\log\pi_k(y_t|x,y_{<t})-\log\pi_0(y_t|x,y_{<t})$。
- 初始路径点间隔 $e_{0,t}=g_{\alpha,t}$，残差 $e_{k,t}=e_{0,t}-\Delta^{(k)}_t$。
- **TSR（Teacher-Signal Realization）**：
  $\text{TSR}^{(k)}=1-\frac{\langle e_k^2\rangle_w}{\langle e_0^2\rangle_w}$，
  0 表示平方间隔未变，1 表示在采样路径上完全闭合。可分解为"位移与路径点间隔的归一化对齐减去归一化位移能量"，从而区分有用移动与过冲/正交移动。
- **Prompt 平衡权重**：$w_{i,t}=\frac{1}{|P|\,|R(p_i)|\,L_i}$，使 prompt、同 prompt 内兄弟响应、响应内有效 token 等质量分配，避免长解与多 rollout 提示主导统计。
- **优势空间统计量**：$M_k=\langle A_0,\log\pi_k(y)-\log\pi_{k-1}(y)\rangle_w$，按 prompt 计算并报告均值、标准误、95% 下置信界（LCB）。$M_k>0$ 表示第 $k$ 次 pass 在冻结 transaction 上取得优势对齐进展——这是**行动前的因果分配分数**。

### 2.4 Allocate：四种实现策略

- **CLOOPD-Fixed2（确定性两遍）**：每批执行 E1+E2，稳定骨干，无阈值校准、无随机分配。
- **CLOOPD-Fixed3（确定性三遍）**：每批执行 E1+E2+E3，暴露可实现深度上界，为控制器设计提供完全观测的边际工作量。
- **CLOOPD-TPMR（Token-Priced Marginal Realization）**：E1+E2 为骨干，E3 为在线动作。定义
  $g_t=\max(\text{LCB}(M_{2,t}),0)$，$u_t=\frac{10^6 g_t}{\max(c_t,1)}$，
  当 $u_t\ge\lambda_{\text{token}}$ 且满足安全、预算、节奏约束时执行 E3。安全包络检查有效实现统计、内部 K3、ESS、有限值与看门狗状态；预算仅在成功 E3 后按其实际活跃 token 数扣费。**token 价格由 CLOOPD-Fixed3 试点校准，仅用 E3 前可得信息，不含 E3 结果或留出准确率。**
- **CLOOPD-Random（预算匹配随机分配）**：共享 TPMR 的 E1+E2 骨干、硬 E3 token 上限、节奏与安全检查，但**不读 $M_2$** 即采样 E3，作为分配对照。

### 2.5 四条闭环不变量

1. rollout 策略 $\pi_0$ 锚定所有采样 token 比值，后续重前向不会悄悄改变参考分布；
2. 近端路径点每批只解一次后冻结；
3. $A_0$ 在 E1/E2 后不重算，每次 pass 优化同一教师诱导排序；
4. 记账按资源归属拆分——有效响应 token 在教师获取侧计一次，在每次执行的 actor pass 侧各计一次。

- **六组 300 步长时程 H20 运行**，覆盖 5 个 benchmark、6 个 checkpoint 网格（50–300 步），每臂 6 个观测点而非挑选最佳 checkpoint。
