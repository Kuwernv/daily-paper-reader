## 摘要
在策略自蒸馏（On-Policy Self-Distillation, OPSD）已成为大语言模型（LLM）自我提升的一种流行范式，它使模型能够利用真实答案等特权信息来充当自身的教师。然而，近期研究发现，OPSD 可能会严重降低 LLM 在复杂推理任务上的性能：通过迫使学生模型模仿以特权信息为条件、人为表现出自信的推理轨迹，OPSD 无意中抑制了不确定性的表达，并惩罚了解决难题所需的探索性与自我纠错行为。为解决这一问题，我们提出负向自蒸馏（Negative Self-Distillation, NSD），一种新的框架，通过远离有缺陷的推理而非模仿特权解决方案来优化 LLM。NSD 不依赖真实答案或外部监督，而是利用模型自身生成针对特定问题的负向条件（例如，扮演“粗心的推理者”），并推动学生模型的分布远离这一自生成的负向教师。简单地应用遗忘学习目标来实现这种偏离是有问题的，因为有缺陷的推理 token 与基础语言 token 相互混杂；不加区分地惩罚二者可能会导致模型的基础语言能力灾难性下降。我们通过设计一种动态门控机制来解决这一问题，该机制能够自动识别并分离对推理至关重要的 token，确保梯度更新仅针对行为缺陷，同时保留模型的语言先验。实证上，NSD 持续优于 OPSD 以及其他无需标签、自举式强化学习（RL）基线。

## Abstract
On-Policy Self-Distillation (OPSD) has emerged as a popular paradigm for large language model (LLM) self-improvement, allowing models to act as their own teachers by leveraging privileged information such as ground-truth solutions. However, recent findings indicate that OPSD can severely degrade the performance of LLMs on complex reasoning tasks: By forcing the student to imitate an artificially confident reasoning trace conditioned on privileged information, OPSD inadvertently suppresses expressions of uncertainty and penalizes the exploratory, self-corrective behaviors required to solve challenging problems. To address this, we introduce Negative Self-Distillation (NSD), a new framework that optimizes LLMs by diverging from flawed reasoning rather than imitating privileged solutions. Instead of relying on ground-truth answers or external supervision, NSD uses the model itself to generate a question-specific negative condition (eg, acting as a ``careless reasoner'') and pushes the student's distribution away from this self-generated negative teacher. Naively applying unlearning objectives to achieve this divergence is problematic, as flawed reasoning tokens are confounded with basic linguistic tokens; indiscriminately penalizing both risks catastrophically degrading the model's foundational language capabilities. We resolve this by designing a dynamic gating mechanism that automatically identifies and isolates reasoning-critical tokens, ensuring gradient updates target only behavioral flaws while preserving the model's linguistic priors. Empirically, NSD consistently outperforms OPSD and other label-free, self-bootstrapping reinforcement learning (RL) baselines.

# 论文总结：Negative Self-Distillation（负向自蒸馏）

## 1. 核心问题与研究动机

- **背景**：RLVR（可验证奖励强化学习）是提升 LLM 推理能力的主流范式，但存在计算低效、奖励信号稀疏、组内优势坍缩、token 级信用分配粗糙等问题。On-Policy Distillation（OPD）借助外部强教师提供稠密监督，但难以获得严格更优且 tokenizer 兼容的外部教师。On-Policy Self-Distillation（OPSD）让模型以真实答案为特权信息充当自身教师，成为一种可扩展替代方案。
- **核心问题**：OPSD 的教师因已知标准解，会产生**人为自信、高度线性的推理轨迹**。迫使学生最小化与该教师的分布差异，会无意中**抑制不确定性表达、探索行为与自我纠错能力**，从而在复杂推理任务上严重退化性能。
- **整体含义**：论文主张从“模仿特权解”转向“**远离缺陷推理**”，提出 NSD——一个完全自举、无需标签、无需外部教师的自蒸馏框架，在保护语言先验的同时提升推理能力。

## 2. 方法论

### 核心思想
不依赖真实答案，而是让模型**自生成问题特定的负向条件**（如“扮演粗心的推理者”），构造负向教师 π_neg，推动学生分布远离该负向教师，同时用参考模型 π_ref 进行锚定。

### 关键技术细节
- **负向条件生成**：对问题 x，学生先采样初始解 y_init，再以 (x, y_init) 为条件生成负向条件 n（在线策略）。也支持离线变体：solution-aware、question-only、wiki-irr（无关维基噪声）。
- **双教师构造**：π_ref 仅以问题为条件（良性概率）；π_neg 以问题+负向条件为条件（负向概率）。两者共享初始模型权重，仅上下文不同。
- **动态 token 门控**：
  `G_t = max(0, π_neg(y_t) − π_ref(y_t))`
  当负向条件提升某 token 概率时才激活惩罚，权重与正差距成正比，自动过滤普通语法 token。
- **Sigmoid 有界非似然惩罚**：
  `L_GU = G_t · σ(−log(1−π_θ)) = G_t · (1/2 − π_θ)`
  避免标准非似然在 π_θ→1 时的梯度爆炸（标准梯度 ∝ π_c；Sigmoid 梯度 ∝ π_c(1−π_c)/(2−π_c)²，在 π≈0.67 处最大，π→1 时衰减为 0）。
- **KL 正则项**：采用单样本重要性加权的前向 KL 锚点
  `L_KL = π_ref · log(π_ref / π_θ)`，防止分布过度漂移。
- **总目标**：`L_NSD = L_GU + α · L_KL`，逐 token 聚合为整体目标 J(θ)。

### 算法流程（Algorithm 1）
1. 初始化学生 π_θ，冻结 π_ref、π_neg ← π_θ0；
2. 对每个问题采样轨迹 y 与负向提示 n；
3. 逐 token 计算 p_ref、p_neg、p_θ；
4. 计算门控 G_t，更新 `L_NSD = G_t/(2−p_θ) + α·p_ref·log(p_ref/p_θ)`；
5. 累加损失并更新参数。

## 6. 主要结论与发现

- **性能**：NSD 在 1.7B/4B/8B 上分别取得 **+2.3%、+7.5%、+6.0%** 的平均绝对提升，持续优于 OPSD、Intuitor、TTRL。4B 与 8B 在 AIME 系列上达到 35.8% 与 39.6% 的峰值准确率。
- **规模效应**：更大模型受益更明显，因在线自生成负向条件质量更高，提供更强的对比训练信号。
- **反思行为**：NSD 显著提升反思 token 频率（平均 7.5 次/响应），而 OPSD 降至 2.2、Intuitor 降至 0.8，说明 NSD 避免过度自信、保留自我纠错。
- **效率**：NSD 训练比 OPSD 与 Intuitor 更快（单次 rollout、并行前向预填充、仅标量损失计算），wiki-irr 进一步将延迟从 68s 降至 54s。
- **鲁棒性**：question-only（+7.3%）与 wiki-irr 等轻量负向条件策略均接近在线 solution-aware 的效果，显示框架可扩展性。
- **稳定性**：KL 约束不可或缺，去除后训练中期出现 KL 崩溃与门控失效。
- **门控优势**：NSD 门控的风格-任务比为 2.6×–3.5×，优于熵加权（3.9×）与 OPSD 损失加权（5.4×）。

## 7. 优点

- **范式创新**：首次系统提出以“远离缺陷”而非“模仿特权解”为核心的自蒸馏框架，完全无需 gold label 与外部教师。
- **训练稳定性设计精巧**：Sigmoid 有界非似然将强梯度集中在中等置信度的推理关键 token 上，天然规避高置信度结构 token 的梯度爆炸。
- **自适应门控**：以 π_neg 与 π_ref 的概率差自动识别推理敏感 token，无需人工标注任务/风格 token。
- **计算高效**：单 rollout、双教师共享权重可并行预填充、仅需三个标量概率，避免全词表 logit 对齐。
- **实验严谨**：多尺寸、多基准、多评测模式，含统计显著性检验与充分消融；案例研究直观展示模型放弃错误路径、切换到正确解法。
- **可扩展性**：NSD 目标可自然嵌入策略梯度框架（advantage = −L_NSD），并兼容多种负向条件策略。

## 8. 不足与局限

- **依赖学生自身能力**：NSD 需要模型能生成有意义的负向条件，对极弱或极小模型可能效果有限（作者在 Limitations 中承认）。
- **在线策略开销**：在线生成负向条件引入额外 rollout 时间；虽可用 wiki-irr 等离线策略缓解，但性能与开销存在权衡。
- **领域覆盖单一**：实验仅限数学推理，未验证代码、科学、多跳问答或智能体任务等更广泛场景。
- **规模效应双刃剑**：小模型（1.7B）增益明显弱于大模型，方法的普适性受模型能力门槛限制。
- **算力信息不完整**：未报告总训练时长与总 GPU 小时，难以精确评估训练成本。
- **负向条件质量评估间接**：缺乏对负向条件本身“缺陷定位准确性”的独立量化指标，其效果主要通过下游性能间接反映。
- **潜在偏差风险**：wiki-irr 在策略梯度设定下表现最佳，与监督目标下在线策略最佳的结论不一致，说明最优策略依赖训练目标形式，需谨慎选择。
- **与 label-dependent 方法的比较边界**：OPSD 使用额外监督，作者将其定位为参考而非严格对等基线，跨范式对比的解释需保留。
