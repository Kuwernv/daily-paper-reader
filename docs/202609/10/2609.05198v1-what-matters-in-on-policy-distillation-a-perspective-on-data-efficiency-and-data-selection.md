## 摘要
同策略蒸馏（On-Policy Distillation, OPD）已成为一种广泛采用的后训练范式，用于增强大语言模型在推理领域的能力。然而，OPD 中以数据为中心的机制仍相对未被充分探索。本文对 OPD 中的数据效率与数据选择进行了实证研究。我们首先考察一种极端设置：仅使用一个样本训练 OPD，即 1-shot OPD。令人惊讶的是，我们发现 1-shot OPD 在所有采样的训练样本上都持续有效，并且更难的样本往往带来更优的性能提升。接着，我们研究训练数据中究竟是什么驱动了学生模型的提升。我们的分析表明，这种提升并非由高 token 熵驱动，而是由难题自然生成的更长 CoT 路径所驱动。在更长的 CoT 上训练有助于在长推理跨度上保持与教师更紧密的对齐，并学习短 CoT 中通常缺失的关键思维模式，例如反思（如“Alternatively”）。基于这些洞见，我们提出一种简单的数据选择方法，仅选择困难样本进行训练；即使完全超出教师能力的“不可解”样本也能被成功使用。我们在四个从 1.5B 到 7B 的模型上进行的实验表明，仅用 8 个选定的困难样本训练学生模型，即可匹配 17K 数据集基线的性能。

## Abstract
On-Policy Distillation (OPD) has emerged as a widely adopted post-training paradigm for enhancing large language models in reasoning domains. However, the data-centric mechanisms in OPD remain relatively underexplored. This paper presents a empirical study of data efficiency and data selection in OPD. We begin by investigating an extreme setting: training OPD on only one example, namely 1-shot OPD. Surprisingly, we find that 1-shot OPD is consistently effective across all sampled training examples and harder examples often yield superior performance gain. We next investigate what actually drives the student model's improvement in the training data. Our analysis reveals that the improvement is not driven by high token entropy, but the longer CoT paths which hard problems naturally generate. Training on longer CoT can help maintain closer alignment with the teacher over a long reasoning horizon, and learn critical thinking patterns usually missing in short CoTs, such as reflection (e.g., ``Alternatively''). Based on these insights, we propose a simple data selection method that selects only hard examples for training, where even ``unsolvable'' examples that completely exceed the teacher's capability can be successfully used. Our experiments conducted on four models ranging from 1.5B to 7B show that training the student model on only 8 selected hard examples matches the performance of the 17K dataset baseline.

## 1. 核心问题与研究动机

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）已成为大语言模型（LLM）后训练的核心技术之一，被 Qwen3、MiMo、GLM-5 等工业级模型采纳，用于将强教师模型的推理能力迁移到小规模学生模型。OPD 通过在学生自身策略采样的轨迹上计算反向 KL 散度进行训练，相比 SFT 能缓解 exposure bias 问题。
- **研究空白**：现有工作主要聚焦于算法改进（如 EOPD、REOPOLD、Prune-OPD 等），而 OPD 的**数据侧机制**（需要多少数据、什么样的数据最有效、数据中什么因素驱动学生提升）仍相对未被充分探索。
- **现实意义**：在医学、工程等专业领域，高质量数据极度稀缺或采集成本高昂，因此系统研究 OPD 的数据必要性具有重要实用价值。
- **核心研究问题**：① OPD 究竟需要多少数据？② 哪类数据最有效？③ 训练数据中究竟是什么驱动了学生模型的提升？

## 2. 方法论

### 2.1 核心思想

- 从极端设置出发——**1-shot OPD**（仅用 1 个训练样本），作为剥离数据多样性影响的干净基线，据此反推 OPD 的数据效率本质与数据选择准则。
- 最终提出一种**难度驱动的数据选择方法**：仅选取困难样本（甚至完全超出教师能力的"不可解"样本）进行训练。

### 2.2 关键技术细节

- **OPD 目标函数**：在学生的 on-policy 轨迹上最小化序列级反向 KL 散度  
  $\mathcal{L}_{OPD}(\theta)=\mathbb{E}_{x\sim\mathcal{D}_x}\left[D_{KL}(\pi_\theta(\cdot|x)\|\pi_T(\cdot|x))\right]$  
  可自回归分解为精确的 token 级形式，即对学生生成的每个前缀 $\hat{y}_{<t}$ 计算学生分布 $p_t$ 与教师分布 $q_t$ 之间的 KL。
- **Top-k OPD**：将散度计算限制在学生概率最高的 k 个 token 子集 $S_t=\text{TopK}(p_t,k)$ 上，并在该子集内重归一化学生与教师分布，计算子集 KL 散度。本文默认采用**学生 top-k** 变体（k=16），显著降低显存开销，同时保留学生活跃生成区域内的稠密多 token 监督。
- **难度划分方法**：对学生模型（DeepSeek-R1-Distill-Qwen-1.5B）和教师模型（JustRL-DeepSeek-1.5B）各进行 16 次 rollout，计算每个问题的平均准确率 $A_i=(S_i+T_i)/2$，并据此分为三类：
  - Easy：$A_i > 0.9$
  - Medium：$0.1 \le A_i \le 0.9$
  - Hard：$A_i < 0.1$
- **长度控制实验设计**：通过限制最大 rollout 长度，使几乎全部响应被截断（>99.5%），从而在 token 数几乎相同的条件下分离 **token 熵** 与 **CoT 长度** 两个变量。
- **政策对齐度量**：采用 **Overlap Ratio**（学生与教师 top-16 词表分布的交集 token 比例），在 100 个 held-out 问题上每问题 16 次 rollout 计算。

### 2.3 数据选择流程（文字描述）

1. 在学生与教师模型上分别对候选池问题做 16 次 rollout，计算平均准确率 $A_i$；
2. 按 $A_i$ 降序、原始索引升序排序，形成确定性序列；
3. 仅选择 $A_i < 0.1$ 的困难样本构成训练集；
4. 从小到大缩放训练集规模 $N \in \{1, 4, 8, 16, 64\}$，观察性能饱和点。

## 3. 实验设计

### 3.1 数据集与场景

- **训练数据池**：从 DAPO-Math-17K 中随机采样 1,000 个数学推理问题，作为 1-shot / few-shot 实验的示例池；全量基线使用完整 17K 数据集。
- **学生/教师默认对**：DeepSeek-R1-Distill-Qwen-1.5B（学生）与 JustRL-DeepSeek-1.5B（教师）。
- **验证集**：AMC 2023、AIME 2024、AIME 2025（每问题 16 次 rollout，mean@16）。
- **评测基准**（6 个数学推理基准）：AIME 2024、AIME 2025、AMC 2023、MATH500、Minerva Math、OlympiadBench；AIME 系列与 AMC 用 mean@16，其余用 mean@4，温度 0.7，最大输出长度 16,384 tokens。

### 3.2 对比方法

- 基线：学生 Base 模型、教师 Teacher 模型、Full-Set OPD（17K 全量蒸馏）、DAPO-Subset（1K 随机子集）。
- 1-shot OPD：从 Easy / Medium / Hard 三类各随机抽 8 个样本（共 24 个）单独训练并对比。
- Few-shot OPD：Hard 样本规模 $N \in \{1, 4, 8, 16, 64\}$；固定 8 样本下对比 Easy / Medium / Hard。
- 跨模型泛化：额外三组教师–学生对：
  1. Skywork-OR1-Math-7B → DeepSeek-R1-Distill-Qwen-7B
  2. Qwen3-4B → Qwen3-1.7B-Base
  3. Qwen3-4B → Qwen3-4B-Base

### 3.3 消融与分析实验

- 1-shot OPD 延长训练至 2,000 步，检验是否过拟合或策略崩溃；
- token 级 KL 缩减分析（top-16 token 对齐）；
- 长度控制实验（1K / 2K / 4K 三组对比）；
- 温度扰动实验（对 Easy 问题 π178 以 $T \in \{0.6, 0.8, 1.0, 1.1\}$ 人为提升 token 熵）；
- Token 位置级 KL loss 分析（比较 2K / 4K / 7K 模型）。

  - **优点**：覆盖了不同难度、不同规模、不同模型架构与参数规模（1.5B–7B）、不同教师能力水平；长度控制实验设计精巧，能有效分离 CoT 长度与 token 熵两个混淆变量；对 1-shot 稳定性的 2,000 步延长验证较为充分。
  - **公平性**：1-shot 与 Full-Set 在相同训练步数（279 步）下对比，控制较好；难度划分使用学生与教师的平均准确率，避免了单侧偏置。

## 6. 主要结论与发现

- **1-shot OPD 持续有效**：在所有采样的 24 个训练样本上，仅用 1 个样本训练即可带来显著的验证性能提升，最佳样本 {π973} 达 51.7% 平均准确率，接近 Full-Set 的 53.7%。
- **训练极其稳定**：1-shot OPD 训练至 2,000 步无过拟合、无策略崩溃，验证性能在约 300 步后进入平台期并保持稳定——与 SFT / RL 在单样本设置下的严重过拟合形成鲜明对比。
- **难题优于简单题**：在 1-shot 和固定 8-shot 设置下，Hard 样本一致优于 Easy 和 Medium；即使训练准确率恒为 0%（学生与教师均无法解出）、完全超出教师能力的"不可解"样本，仍能持续提升验证准确率。
- **提升由 CoT 长度而非 token 熵驱动**：长度控制实验表明，一旦 rollout 长度被限制到相同水平，不同熵样本的性能差距收缩至 ±1% 以内；而高温度扰动提升熵也不带来增益。
- **长 CoT 带来长程对齐与高级推理模式**：7K 模型在全生成跨度上 KL 散度持续低于 2K/4K 模型；超过 4,000 token 后差距扩大，说明长 CoT 训练直接增强长程推理能力。反思 token（如 "Alternatively"）在 Easy 模型 top-16 KL 缩减列表中缺失，在 Medium 中出现，在 Hard 中排名更高。
- **极端数据效率**：1.5B 学生模型仅用 8 个精选困难样本即达 53.6% 平均准确率，几乎匹配 17K 全量基线（53.7%）；增至 16 或 64 个无额外收益。
- **跨模型泛化**：在 1.5B–7B、不同架构的教师–学生对上，few-shot（1/4/8-shot）困难样本训练均能逼近 17K 全量基线（如 DeepSeek-7B 学生 8-shot 达 59.5% vs Full-Set 59.6%）。

## 7. 优点

- **问题新颖且实用**：首次系统性地从数据效率与数据选择角度研究 OPD，填补了算法侧研究之外的空白，对数据稀缺场景具有直接指导意义。
- **实验设计精巧**：1-shot OPD 作为极端基线干净有力；长度控制实验通过截断 rollout 有效分离了 CoT 长度与 token 熵两个混淆因素；温度扰动辅助实验进一步交叉验证。
- **机制分析深入**：不仅报告现象（难题更好），还从 token 级 KL 缩减、位置级 KL loss、Overlap Ratio、反思 token 出现位置等多个角度解释"为什么"，形成了较完整的因果链条。
- **方法极简**：数据选择仅需按准确率排序取困难样本，零额外优化参数、零复杂流程，易于工业落地。
- **泛化验证扎实**：在 4 个模型（1.5B、1.7B、4B、7B）、3 组不同教师–学生对上验证，结论稳健。
- **无验证器场景的替代方案**：讨论部分提出以 CoT 长度作为无验证器领域的难度代理，具有实践推广价值。

## 8. 不足与局限

- **数据选择非最优**：作者自述难度驱动选择是简单经验性选择，而非数学上最优；寻找理论最优训练集可能计算不可行。
- **依赖规则验证器**：数学/代码领域可用 verifier 计算准确率来划分难度，但医学、通用推理等无验证器领域无法直接套用，只能退而用 CoT 长度代理（尚未实验验证）。
- **长 rollout 的曝光偏差权衡**：更长轨迹虽含更丰富模式，但学生自身错误会在长跨度上累积，导致偏离分布、削弱教师监督质量；最大长度 7,168 为经验选择，非最优。
- **任务覆盖单一**：所有实验集中在数学推理基准（AIME/AMC/MATH500/Minerva/Olympiad），未涉及代码、多语言、开放域问答或智能体任务，结论的外推性有待验证。
- **算力信息不完整**：仅报告 GPU 型号与数量（8×H800），未给出总训练时长、总 GPU 小时或能耗数据，复现成本评估不充分。
- **样本池规模有限**：训练示例池仅从 17K 中采样 1,000 个，Hard 类别仅 175 个，16/64-shot 需随机补充样本，可能引入采样偏差。
- **缺少与 SFT/RLVR 的横向对照**：论文主要与自身 Full-Set 基线对比，未与同等数据量下的 SFT 或 RLVR 方法做直接比较，难以判断 OPD 数据效率优势的相对幅度。
