## 摘要
同策略蒸馏（OPD）为语言模型后训练提供密集的逐 token 监督，但其有效性受限于教师质量：外部教师存在分布不匹配问题，而带有特权条件信息的自蒸馏则受限于上下文学习能力。我们提出 RISE（Recursive Improvement via Self-Extrapolating Policy Distillation，通过自外推策略蒸馏实现的递归改进），它直接从模型自身的 RLVR 训练轨迹中构建一个合成教师。通过外推当前检查点与滞后锚点之间的位移——无论是在参数空间还是输出 logit 空间——RISE 将稀疏的由结果诱导的参数更新转化为密集的 token 级目标，且无需任何外部模型或特权条件。RISE 将 RLVR 与 OPD 结合为一个互补循环：结果奖励使外推锚定于正确推理，而外推出的教师则细化 token 级决策。此外，由于教师会随着学生模型的改进而在每次迭代中刷新，蒸馏便成为一种递归改进机制，而非一次性的压缩步骤。涵盖数学推理、多领域 STEM、代码生成和多轮智能体任务的实验表明，RISE 在所有设置中均优于仅使用 RLVR 的训练和同策略自蒸馏。

## Abstract
On-policy distillation (OPD) provides dense, per-token supervision for language model post-training, but its effectiveness is bottlenecked by teacher quality: external teachers suffer from distribution mismatch, while self-distillation with privileged conditioning is limited by in-context learning capacity. We propose \textbf{RISE} (\textbf{R}ecursive \textbf{I}mprovement via \textbf{S}elf-\textbf{E}xtrapolating Policy Distillation), which constructs a synthetic teacher directly from the model's own RLVR training trajectory. By extrapolating the displacement between the current checkpoint and a trailing anchor---in parameter space or output logit space---RISE converts a sparse outcome-induced parameter update into a dense token-level target, without any external model or privileged conditioning. RISE combines RLVR and OPD in a complementary loop: outcome rewards ground the extrapolation toward correct reasoning, while the extrapolated teacher refines token-level decisions. Moreover, since the teacher is refreshed every iteration as the student improves, distillation becomes a recursive improvement mechanism rather than a one-shot compression step. Experiments spanning mathematical reasoning, multi-domain STEM, code generation, and multi-turn agentic tasks show that RISE outperforms RLVR-only training and on-policy self-distillation across all settings.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：大语言模型（LLM）后训练正从依赖人类监督转向自我改进。RLHF/RLVR、自博弈、拒绝采样微调等方法共享一个根本局限——**学习信号是序列级的**（结果奖励、二值接受/拒绝标签或标量偏好），无法告诉模型哪些 token 对成功或失败负责，形成**信用分配瓶颈**。
- **OPD 的价值与瓶颈**：同策略蒸馏（On-policy Distillation, OPD）通过教师模型在每个位置提供完整的下一 token 分布，为权重更新提供密集的逐 token 监督，理论上比稀疏结果奖励信息量更大。但 OPD 的承诺取决于一个关键问题：**可靠的教师从哪里来？**
  - **外部教师 OPD**：学生探索出教师未见过的推理路径时，教师在分布外前缀上的条件分布不可靠，前缀分布不匹配会恰好在学生最需要指导时降低教师质量。
  - **同策略自蒸馏（OPSD）**：以特权信息（正确解、环境反馈）为条件让同一基座模型充当教师，但受限于模型的上下文学习（ICL）能力，且师生输入不同造成另一类分布不匹配。
  - **启发式补救**：token 级门控、散度混合、DAgger 式采样、轨迹精炼等，均是接受一个"有缺陷的教师"并设法容忍其噪声，而非追问"教师应该是什么"。
- **核心洞察与整体含义**：论文提出一个视角转换——策略 πθ 的自然教师候选者是它自己**收敛后的未来自我** π*。虽然 π* 未知，但训练轨迹揭示了收敛方向。RISE 通过外推模型自身 RLVR 训练轨迹中的位移来构造合成教师，**无需外部模型、无需特权条件**。由于教师随学生迭代刷新，蒸馏从一次性压缩步骤转变为**递归自我改进机制**。

## 2. 方法论：核心思想、技术细节与算法流程

### 2.1 核心思想：自外推教师构造

- 设 φ 为将策略映射到可做线性运算的向量空间的表示映射。定义**自外推教师**：
  - φ(π_future) = φ(π_θn) + β·[φ(π_θ′_{n+1}) − φ(π_θn)]，β > 1
  - β = 1 时教师等于当前检查点（无蒸馏信号）；β > 1 时放大模型最近一次的更新，沿训练轨迹向当前状态之外投影。
- **理论依据**：后训练更新由低秩子空间主导且近似线性演化（Cai et al., 2025; Wang et al., 2026a），使沿训练方向的外推成为有原则的近似。附录 A.3 实测：RLVR 权重轨迹前 3 个主成分在 1.7B 和 8B 上分别解释 86.6% 和 88.5% 的方差。

### 2.2 两种实例化方式

| 空间 | 公式 | 特点 |
|------|------|------|
| **权重空间**（φ = θ） | θ_future = θn + β·(θ′_{n+1} − θn) | 即带外推系数的任务算术；生成连贯模型，跨位置预测联合一致；需物化参数，每个 OPD 步骤一次教师前向 |
| **Logit 空间**（φ = log π） | log π_future = log π_θn + β·(log π_θ′_{n+1} − log π_θn) + const | 等价于几何混合 π_future ∝ π^(1−β)_θn · π^β_θ′_{n+1}；无需参数操作，教师可在 OPD 前固定；是权重空间外推的一阶泰勒近似 |

- **与 KL 正则的联系（Remark 1）**：D_KL(πθ ∥ π_future) = −(β−1)·D_KL(πθ ∥ π_θn) + β·D_KL(πθ ∥ π_θ′_{n+1}) + log Z。β > 1 时第一项为负系数、具有排斥性（推离锚点、延续 RLVR 改进方向），第二项将策略正则化到 RLVR 后的检查点，防止 OPD 期间过冲。

### 2.3 训练流程（两阶段交替）

1. **RLVR 阶段**：从当前策略 π_θn 采样 rollout，计算结果奖励，用 GRPO 等策略梯度方法更新得到 θ′_{n+1}。
2. **OPD 阶段**：由 θ′_{n+1} 与锚点 π_θn 构造 π_future，通过最小化 L_RISE 将 π_future 蒸馏回 θ′_{n+1}，得到 θ_{n+1}。

- **互补性**：RLVR 通过稀疏结果奖励发现能力改进方向；OPD 将外推教师的 token 级分布压缩进当前策略。两阶段复用同一批 rollout，**不增加额外采样成本**。
- **蒸馏损失**：L_RISE = E_{y∼πθ}[Σ_t D_KL(πθ(·|s_t) ∥ sg[π_future(·|s_t)])]，π_future 全程 stop-gradient。实践中用**Jensen–Shannon 散度（JSD）**替代 KL，因 JSD ≤ log 2 且与 KL 共享唯一最小值点。
- **Top-K 近似**：全词表散度计算不可行，采用 K=100（代码任务 K=20）的 top-K 加 tail 桶投影到 (K+1) 维单纯形，再施加外推公式。K=100 时 top-K 覆盖 >99% 概率质量，偏差可忽略。
- **外推衰减**：固定 β 不适用于整个训练轨迹。采用单调递减调度 βn = 1 + (β0−1)(1−n/N)，早期激进外推、后期收缩至安全范围（对应 Proposition 3：安全 β 范围随策略趋近最优而收窄）。
- **锚点动态**：默认锚点为上一检查点 θn；可选 EMA 锚点 θ_anchor ← (1−η)θ_anchor + ηθ_{n+1}，平滑并放大位移。η=1 即上一检查点。
- **OPD 的作用**：外推点位于策略信任域之外，直接采纳风险大；OPD 充当**信任域投影**，将策略推向 π_future 的 token 级分布，同时散度项使更新锚定在 θ′_{n+1} 附近。RISE 不引入超出 RLVR 的新任务信息，仅利用模型自身归纳结构将稀疏结果更新转化为密集 token 级目标。

### 2.4 理论分析（附录 A）

- **Theorem 2（次优性分解）**：J(π*) − J(πθ) ≤ [J(π*) − J(πT)] + T·√(L̄_OPD/2)，将误差分解为**教师差距**（持续存在，与优化质量无关）和**蒸馏误差**（OPD 收敛时消失）。
- **Proposition 3（线性轨迹下的安全外推范围）**：当且仅当 1 < β < 2α*/αn − 1 时，外推教师比学生更接近 π*；上限随 αn → α* 而收缩。
- **Corollary 4**：RISE 单次迭代使 Lipschitz 次优性界按 γ(β) < 1 收缩，γ(β) = (α* − βα′_{n+1})/(α* − α′_{n+1})。
