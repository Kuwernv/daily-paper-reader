## 摘要
视觉-语言-动作（VLA）模型的有效在线适应仍然具有挑战性，因为稀疏奖励为高维自回归动作策略提供了较弱的监督。尽管自蒸馏原则上可以提供更密集的训练信号，但我们发现基于示范、检索经验或高级规划的文本特权教师对于VLA适应无效，揭示了符号引导与低级机器人动作之间的模态差距。我们提出了ROAD-VLA，一种优势引导的自蒸馏框架，通过使用校准的优势估计扰动动作标记对数几率，直接在动作空间中构建一个邻近教师。这将在保持教师接近当前策略的同时，将稀疏奖励转化为密集的标记级监督。我们进一步推导了在校准优势和准确教师匹配下的策略改进下界。在七个具有分布内和分布外变化的机器人操作环境中，ROAD-VLA在几乎所有的设置中都优于PPO，展示了鲁棒的在线VLA适应。

## Abstract
Effective online adaptation of vision-language-action (VLA) models remains challenging, as sparse rewards provide weak supervision for high-dimensional autoregressive action policies. Although self-distillation can in principle provide denser training signals, we find that text-based privileged teachers conditioned on demonstrations, retrieved experiences, or high-level plans are ineffective for VLA adaptation, exposing a modality gap between symbolic guidance and low-level robot actions. We propose ROAD-VLA, an advantage-guided self-distillation framework that constructs a proximal teacher directly in action space by perturbing action-token logits with calibrated advantage estimates. This converts sparse rewards into dense token-level supervision while keeping the teacher close to the current policy. We further derive a policy-improvement lower bound under calibrated advantages and accurate teacher matching. Across seven robotic manipulation environments with in-distribution and out-of-distribution shifts, ROADVLA outperforms PPO in nearly all settings, demonstrating robust online VLA adaptation.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉‑语言‑动作（VLA）模型在部署后需要在线适应环境变化（分布偏移），但传统的强化学习方法（如 PPO）面临**稀疏奖励**带来的高方差、优化不稳定和灾难性遗忘问题。
- **背景局限**：自蒸馏（self‑distillation）在 LLM 微调中成功，但在 VLA 中却失效——因为文本形式的教师（如高级规划、检索动作）与低级连续动作之间存在**模态差距**，VLA 在微调后丢失了 LLM 的推理能力，语言提示难以转化为精确的控制信号。
- **整体含义**：本文提出一种新的自蒸馏范式——**在动作空间构建教师**，利用优势估计直接扰动动作 token 的 logits，将稀疏的标量奖励转化为密集的 token 级监督，从而弥合符号与动作之间的鸿沟。

## 2. 方法论

### 核心思想
- 在在线 rollout 过程中，利用当前策略（student）的**优势估计**（advantage）构建一个**邻近教师**（proximal teacher），该教师通过扰动 student 的动作 token logits 得到，扰动幅度由校准后的优势值决定。
- 学生通过 KL 散度蒸馏到该教师分布上，从而将标量奖励转化为**每个 token 的密集监督**，且教师始终靠近当前策略，防止漂移。

### 关键技术细节
1. **优势估计与校准**：
   - 同时使用在线 critic 和冻结的 PPO 参考 critic，得到两个优势估计 `A_int` 和 `A_ref`。
   - 对参考优势进行**幅值校准**（均值/标准差匹配），再通过**符号一致性门控**（sign‑agreement gate）混合：仅当两者符号一致时才使用混合优势 `A_mix`，否则只用在线优势。
2. **扰动权重**：
   - 将混合优势标准化并裁剪到 `[-c, c]`（c=2），得到签名权值 `ω_t`（可正可负）。
3. **邻近教师构建**：
   - 对于每个动作 token k，给定 student logits `z_t,k` 和采样的 token `â_t,k`，构造教师分布：
     ```
     q*_t,k = softmax(z_t,k + η ω_t e_{â_t,k})
     ```
     其中 η=1，e 为 one‑hot 向量。这等价于一个 KL‑正则化的局部改进问题的闭式解。
4. **蒸馏目标**：
   - 使用 **Forward KL** 散度（默认）对学生进行蒸馏：
     ```
     L_AGD = E[ (1/TK) Σ_t Σ_k KL(q*_t,k || pθ_t,k) ]
     ```
     相较于 PPO 仅用标量权重重采样动作，此目标提供对每个 token 的密集梯度。
5. **理论保证**：
   - 定理 1 证明了在温和的校准条件下，蒸馏到优势引导教师可以导出一个策略改进下界，确保策略提升。

### 算法流程（文字描述）
```
1. 收集 on‑policy rollout
2. 对每个 timestep：
   - 计算在线优势 A_int 和参考优势 A_ref
   - 校准参考优势，检查符号一致性，得到混合优势
   - 标准化并裁剪得到权值 ω_t
   - 对每个 token，用 ω_t 扰动 student logits 得到教师分布
3. 计算 token 级 Forward KL 蒸馏损失
4. 更新 student 参数
```

- ROAD‑VLA **在几乎所有 ID 和 OOD 设置下优于 PPO**：平均 ID 成功率从 85%→88%，OOD 从 69%→73%，平均退化幅度从 16.3% 降至 14.6%。

- **训练动力学**：ROAD‑VLA 收敛更快、峰值更高、训练后期方差更低。
