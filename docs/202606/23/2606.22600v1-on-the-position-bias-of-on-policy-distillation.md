## 摘要
在线策略蒸馏（OPD）通过教师提供的密集、词元级监督提升了标准强化学习的学习效率。在OPD的标准KL目标中，词元级损失被均匀平均，意味着所有词元具有相同权重。然而，我们发现并非所有词元都是平等的：随着学生 rollout 变长，它们与教师分布的偏差增大，导致后期位置的监督质量下降。因此，仅使用前30%词元的OPD可以达到与使用全部词元相当的性能，而仅使用后30%词元的OPD几乎学不到任何东西。在本工作中，我们通过约束优化的视角为这一问题提供了原则性的理解。基于这些见解，我们推导出重要性加权在线策略蒸馏（IW-OPD），其中分配给每个词元的权重取决于学生与教师分布之间的累计差异，自然地提升早期词元的权重并降低偏差较大的后期词元权重。我们证明，IW-OPD 的收敛速度显著快于 OPD，具有更高的学习效率，并且在同尺寸和跨尺寸设置下均能达到比标准 OPD 更好的最终性能，在 AIME-2025 上性能提升高达 6.9 分。

## Abstract
On-Policy Distillation (OPD) improves the learning efficiency of standard reinforcement learning through dense, token-level supervision from teachers. In the standard KL objective of OPD, token-level losses are uniformly averaged, implying equal weights for all tokens. However, we discover that not all tokens are created equal: as student rollouts grow longer, they deviate further from the teacher's distribution, leading to degraded supervision quality at later positions. As a result, OPD using only the first 30% of tokens can perform comparably to using all tokens, whereas OPD using only the last 30% of tokens barely learns anything. In this work, we provide a principled understanding of this issue through the lens of constrained optimization. Based on these insights, we derive Importance-Weighted On-Policy Distillation (IW-OPD), in which the weight assigned to each token depends on the accumulated discrepancy between the student's and teacher's distributions, naturally upweighting earlier tokens and downweighting later ones with larger deviations. We show that IW-OPD converges significantly faster than OPD, with better learning efficiency, and achieves better final performance than standard OPD in both same-size and cross-scale settings, improving performance up to 6.9 points on AIME-2025.

### 论文详细总结

#### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：在线策略蒸馏（On-Policy Distillation, OPD）通过教师模型对学生采样轨迹提供密集的 token 级监督，以提高 LLM 后训练阶段的学习效率。然而，标准 OPD 对所有 token 的 KL 散度损失进行均匀平均，忽略了 token 在序列中的位置差异。
- **核心问题**：作者发现 OPD 存在显著的**位置偏差（Position Bias）**：学生生成的 rollout 越长，其分布越偏离教师分布，导致序列后半部分的监督质量急剧下降。例如，仅使用前 30% token 进行训练即可达到与全序列训练相当的性能，而仅使用后 30% token 则几乎学不到任何东西。
- **整体含义**：该问题揭示 OPD 的 token 级监督并非同等可靠，需要根据轨迹上下文（prefix）动态分配权重，以提升学习效率和最终性能。这为蒸馏策略的设计提供了新的理论视角（有限预算分配下的约束优化）。

#### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：将 OPD 训练视为一个**有限预算的局部投影（constrained local projection）** 问题。在每次更新中，学生策略只能在一定的 KL 半径 ρ 内移动，因此应将有限梯度预算优先分配给那些教师监督仍然可靠的早期 token（即教师-学生分布重叠较大的前缀）。
- **理论推导**：
  - 通过求解约束优化问题：`min_q D_KL(q || π_T) s.t. D_KL(q || π_θ) ≤ ρ`，得到最优策略 `q*_θ(y) ∝ π_θ(y) * (π_T(y)/π_θ(y))^α`，其中 α∈(0,1) 由 ρ 决定。
  - 该最优策略本质上是重采样学生轨迹，根据 teacher/student 似然比加权，越靠后的 token 权重越小。
- **提出的方法：IW-OPD（Importance-Weighted On-Policy Distillation）**
  - **目标函数**：直接优化最优策略与教师的 KL 散度，通过重要性采样转换为标准 OPD 形式但每个 token 的 KL 项乘以一个归一化的**前缀重要性权重** `r̃_t`：
    `J*_IW(θ) = -E_{y~π_θ}[ Σ_t sg[r̃_t] * log(π_θ(y_t)/π_T(y_t)) ]`
  - **稳定权重估计**：直接使用似然比不稳定，因此采用一系列工程技巧：
    1. **对数缩放**：将概率比转换为对数域累积，即 `log r_t = α Σ_{k<t} A_OPD_k`。
    2. **绝对值累积**：将正向/负向优势取绝对值求和，避免符号抵消，得到无符号累积差异。
    3. **归一化**：将每个样本内的权重线性映射到 [0,1] 区间。
    4. **与原始 OPD 插值**：最终权重 `r̃_IW-OPD_t = 1 + γ * (1 - Σ_{k<t}|A_k| / Σ_{k<T}|A_k|)`，默认 γ=0.5，确保保留标准 OPD 的监督基础，同时额外分配预算给可靠前缀。
  - **算法流程**（见原文 Algorithm 1）：在每次迭代中，采样学生轨迹，计算 token 级 OPD 优势，然后按上述公式计算 IW-OPD 优势，代入 PPO 更新。

#### 6. 论文的主要结论与发现

- **位置偏差确实存在且影响显著**：前 30% token 即可匹配全序列 OPD 性能；后缀 30% 几乎无效。
- **IW-OPD 持续优于 OPD**：在所有教师-学生配对和 benchmark 上，IW-OPD 均获得更高最终准确率（提升 1-7 个点不等）且收敛更快（step-10 即达到甚至超过 OPD 最终性能）。
- **IW-OPD 使更强教师更高效**：当教师更强时，标准 OPD 因轨迹不匹配早期效率下降，而 IW-OPD 通过权重重新分配使强教师尽早发挥作用（如 30B-A3B 教师 + 4B 学生，step-10 超越 4B 教师引导的 OPD）。
- **IW-OPD 对小规模学生提升更大**：学生越小（如 0.6B），相对增益越高（最高 +14.9%），表明跨尺度蒸馏中位置偏差问题更严重。
- **权重设计的有效性**：无符号累积差异比有符号累积更稳定；与原始 OPD 混合比单独使用更好；轨迹自适应的累积份额比固定形状策略更优。

#### 7. 优点

- **理论创新**：首次从有限预算约束优化角度解释 OPD 的位置偏差，并导出原则性的重要性权重公式。
- **实用性强**：所提 IW-OPD 仅需额外计算 token 级优势的累积绝对值之和，无需额外教师前向调用或修改训练框架，易于集成到现有 OPD 流程。
- **实验充分**：多个尺度和教师-学生关系下的验证，消融实验清晰展示了各组件贡献。
- **性能提升显著**：尤其在早期训练阶段和跨尺度设置中，提升幅度大，且与 ExOPD 兼容。
