## 摘要
在线自蒸馏通过在模型自身的rollout上训练，并使用冻结副本提供基于参考目标的密集token级目标。这对于LLM推理效果良好，但直接扩展到多模态大语言模型可能会产生捷径：特权目标可能主要基于文本参考目标而非图像来引导token。我们提出ViGOS，一种用于MLLM后训练的视觉引导在线自蒸馏框架。学生模型首先编写视觉描述，然后推理出最终答案。对于有效rollout，仅图像的感知教师监督描述，而特权推理教师监督同一学生前缀上的推理和最终答案。仅对无效rollout使用参考教师以恢复输出格式。在通用视觉-语言、专家推理、视觉数学、空间定位和视觉-语言先验基准测试中，ViGOS保留了在线自蒸馏的主要优势，并在容易产生捷径的设置中改善了基于图像的行为。

## Abstract
On-policy self-distillation (OPSD) trains a model on its own rollouts and uses a frozen copy to provide dense token-level targets conditioned on a reference target. This works well for LLM reasoning, but a direct extension to multimodal large language models (MLLMs) can create a shortcut: the privileged target may guide tokens mainly based on the text reference target rather than the image. We propose ViGOS, a visually grounded OPSD framework for MLLM post-training. The student first writes a visual description and then reasons toward the final answer. For valid rollouts, an image-only perception teacher supervises the description, while a privileged reasoning teacher supervises the reasoning and final answer on the same student prefix. A reference teacher is used only for invalid rollouts to recover the output format. Across general vision-language, expert reasoning, visual math, spatial grounding, and visual-language-prior benchmarks, ViGOS keeps the main benefits of OPSD and improves image-grounded behavior in shortcut-prone settings.

# 论文总结：ViGOS（Visual Grounding On-Policy Self-Distillation）

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：在线自蒸馏（OPSD）在文本语言模型推理中表现优异，通过冻结教师模型为学生提供基于参考答案的密集token级监督。但当直接扩展到多模态大语言模型（MLLM）时，会引入 **“文本捷径”风险**：特权教师仅凭文本参考答案即可引导推理，导致学生模型忽视图像内容，产生弱视觉接地但答案一致的反应链，即“语言先验”问题（类似于VQA中的捷径学习）。
- **核心挑战**：多模态模型中，文本信号（问题、参考答案）比图像更容易被模型利用；在OPSD中，教师在每个token上都使用参考答案，使得答案驱动的监督过早介入，学生可能学会跳过图像证据直接生成与答案匹配的推理。
- **本文目标**：提出一种解耦感知与推理的框架，在保留OPSD密集监督优势的同时，强制模型先基于图像生成视觉描述，再基于描述进行推理，从而抑制文本捷径，提升对图像的依赖。

## 2. 方法论：核心思想、关键技术细节与流程

- **核心思想**：将学生生成序列分为三段：**视觉描述（d）** → **推理过程（r）** → **最终答案（a）**。使用三个冻结的教师拷贝，分别监督不同阶段，且教师上下文不同：
  1. **图像-only感知教师（q_img）**：**仅接收图像**，不接收问题和答案，监督描述段，确保描述源于图像而非文本。
  2. **特权推理教师（q_rea）**：接收图像、问题及参考答案，监督推理段和答案段，即答案引导的推理仅在学生已经生成视觉描述后生效。
  3. **参考教师（q_ref）**：仅在无效rollout（格式错误）时使用，提供完整的特权上下文，以反向KL散度作为回退信号，帮助恢复格式。

- **技术细节**：
  - 学生通过提示生成结构化输出：`<description> d </description> <think> r </think> \boxed{a}`。
  - 训练过程中解析token掩码 T_d，T_r，T_a，以及无效标志 m_inv。
  - 损失函数：
    - 感知损失：L_perc = (1 - m_inv) * Σ_{t∈T_d} D_KL(q_img,t || p_θ,t)
    - 推理损失：L_rea = (1 - m_inv) * Σ_{t∈T_r∪T_a} D_KL(q_rea,t || p_θ,t)
    - 参考回退损失：L_ref = m_inv * Σ_{t∈T_y} D_KL(p_θ,t || q_ref,t) （反向KL）
    - 总损失：L = λ_perc L_perc + λ_rea L_rea + λ_ref L_ref
  - 所有教师来自冻结的学生初始副本（self-distillation），不引入外部大模型。
  - 推理时移除所有教师，仅使用学生。

- **关键设计**：通过解耦，使答案监督只作用于“推理-答案”段，避免直接污染早期视觉描述；同时感知教师仅依赖图像，强制学生从图像中提取证据。

- **基准测试**：

## 6. 主要结论与发现

- ViGOS在8个标准基准上，**保留了OPSD的主要提升**（Pass@5和Avg@5均明显高于Baseline），且与OPSD相当或略微更好（7B上最佳Pass@5）。
- 在ViLP先验冲突测试中，ViGOS在所有设置下均获得最高Score，同时保持高Prior，表明模型能够更好地在冲突情况下依赖图像，而不破坏有用的先验知识。
- PALR诊断显示，ViGOS将推理-答案段的答案驱动监督占比从OPSD的17-26%降低到6-8%，验证了解耦的有效性。
- 消融实验表明，三个教师（感知、推理、参考回退）均不可或缺，特别是去除参考教师会导致ViLP Score大幅下降。
- 同提示控制实验确认，ViGOS的增益主要来自分离监督信号，而非仅靠结构化提示。
