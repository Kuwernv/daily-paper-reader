## 摘要
在线自蒸馏（OPSD）在模型自身的推出上训练模型，并使用冻结副本提供基于参考目标的密集令牌级目标。这对于大语言模型推理效果良好，但直接扩展到多模态大语言模型（MLLM）可能产生捷径：特权目标可能主要基于文本参考目标而非图像来指导令牌。我们提出ViGOS，一种用于MLLM后训练的视觉基础OPSD框架。学生首先撰写视觉描述，然后推理得出最终答案。对于有效推出，仅图像的感知教师监督描述，而特权推理教师在相同的学生前缀上监督推理和最终答案。参考教师仅用于无效推出以恢复输出格式。在通用视觉语言、专家推理、视觉数学、空间定位和视觉语言先验基准测试中，ViGOS保留了OPSD的主要优势，并在易受捷径影响的设置中改善了基于图像的行为。

## Abstract
On-policy self-distillation (OPSD) trains a model on its own rollouts and uses a frozen copy to provide dense token-level targets conditioned on a reference target. This works well for LLM reasoning, but a direct extension to multimodal large language models (MLLMs) can create a shortcut: the privileged target may guide tokens mainly based on the text reference target rather than the image. We propose ViGOS, a visually grounded OPSD framework for MLLM post-training. The student first writes a visual description and then reasons toward the final answer. For valid rollouts, an image-only perception teacher supervises the description, while a privileged reasoning teacher supervises the reasoning and final answer on the same student prefix. A reference teacher is used only for invalid rollouts to recover the output format. Across general vision-language, expert reasoning, visual math, spatial grounding, and visual-language-prior benchmarks, ViGOS keeps the main benefits of OPSD and improves image-grounded behavior in shortcut-prone settings.

### 1. 核心问题与整体含义（研究动机和背景）
- **背景**：在线自蒸馏（OPSD）在语言模型（LLM）推理中表现优异，通过冻结的教师模型在学生的自生推出（rollout）上提供稠密的token级监督，且教师可访问参考答案作为特权信息。直接将该方法扩展到多模态大语言模型（MLLM）时，容易产生“捷径”问题（shortcut）。
- **核心问题**：MLLM同时接收图像和文本输入，但文本（尤其是参考答案）往往是更易利用的信号。在标准OPSD中，特权教师对每一个学生token均以参考答案为条件进行监督，导致学生可能不充分观察图像，便根据文本路径生成与答案兼容的推理，形成“答案→推理→答案”的捷径，弱化了对图像的真实依赖。这与VQA中的语言先验和捷径学习问题密切相关。
- **整体含义**：直接套用OPSD会损害MLLM的视觉基础能力，特别是在图像与文本先验冲突时。作者提出ViGOS，通过解耦感知（视觉描述）与推理，分别使用不同上下文的教师进行监督，从机制上阻断答案对早期视觉描述阶段的直接泄露，从而在保留OPSD密度监督优势的同时，增强模型对图像的依赖。

### 2. 论文提出的方法论

**核心思想**：将学生输出结构化为三段式：视觉描述（description）、推理（reasoning）、答案（answer）。对有效推出，用图像唯一感知教师（仅以图像为外部上下文）监督描述部分；用特权推理教师（带参考答案）监督推理和答案部分。对格式无效的推出，使用参考教师（带参考答案且要求完整格式）进行反向KL散度恢复。所有教师均为学生模型的冻结副本（自蒸馏）。

**关键技术细节**：
- 学生输出格式：`<description> d </description> <think> r </think> \boxed{a}`。
- 解析器提取描述token集T_d、推理token集T_r、答案token集T_a，并检测无效推出。
- 训练目标：
  - 感知损失 L_perc = E[ (1–m_inv) Σ_{t∈T_d} KL(q_img,t ∥ p_θ,t) ]，其中q_img,t = p_θ̄(·|I, h_t)（教师仅见图像和前缀）。
  - 推理损失 L_rea = E[ (1–m_inv) Σ_{t∈T_r∪T_a} KL(q_rea,t ∥ p_θ,t) ]，其中q_rea,t = p_θ̄(·|I, x, a⋆, π_rea, h_t)（教师见图像、问题、参考答案和推理提示）。
  - 参考教师损失 L_ref = E[ m_inv Σ_{t∈T_y} KL(p_θ,t ∥ q_ref,t) ]（反向KL），仅对无效推出生效。
- 总损失：L_ViGOS = λ_perc L_perc + λ_rea L_rea + λ_ref L_ref。
- 推理时仅使用学生模型，无需任何教师。

**特权答案泄露率（PALR）诊断**：为量化捷径，作者提出PALR指标，通过替换参考答案为错误答案或替换图像为错配图像，计算稠密纠正中由答案驱动和图像驱动的相对比例。PALR越高，表示纠正更多源于答案而非图像。该指标用于验证ViGOS的有效性。
