## 摘要
优化监督微调（SFT）的训练数据分布决定了大型语言模型（LLM）的能力上限。现有的数据筛选方法在预算有限时能加速训练，但不太适合提升能力上限。这里的挑战不再是识别一个保留性能的更小子集，而是优化数据分布，使其更有可能提升最终模型。为了解决这个问题，我们探索使用影响力函数（IF）进行实例级数据归因。我们发现标准影响力函数公式在这种设置中存在两个结构性问题：由离策略验证目标引起的邻近差距，以及对梯度范数的严重偏差。我们提出了DRIFT（通过在线策略影响力函数对监督微调进行数据优化）。DRIFT不是依赖外部参考数据，而是利用模型的在线策略生成作为验证目标，这在经验上最小化了参数邻近差距，并更好地符合影响力函数的局部邻域假设。它进一步基于轨迹正确性应用符号加权，并针对梯度攻击问题去偏影响得分，从而允许少量验证查询作为可靠锚点来归因整个数据集。在7B参数指令和推理模型上的实验表明，DRIFT持续提高了两者的性能上限，优于现有的数据筛选基线。

## Abstract
Optimizing the training data distribution for Supervised Fine-Tuning (SFT) dictates the capability of Large Language Models (LLMs). While existing data curation methods excel at accelerating training under constrained budgets, they are less suited to elevating the capability upper bound. The challenge here is no longer to identify a smaller subset that preserves performance, but to refine the data distribution toward instances most capable of improving the final model. To address this problem, we explore instance-level data attribution using Influence Functions (IF). We identify that standard IF formulations struggle in this setting due to two structural limitations: a proximity gap caused by off-policy validation targets, and a severe bias towards gradient norm. We propose DRIFT (Data Refinement via On-Policy Influence Functions for Supervised Fine-Tuning). Instead of relying on external reference data, DRIFT utilizes the model's on-policy rollouts as validation targets, which empirically minimizes the parameter proximity gap and better aligns with the local neighborhood assumption of IF. It further applies signed weighting based on trajectory correctness and debiases influence scores against the gradient hacking issue, allowing a small set of validation queries to act as reliable anchors for attributing the full dataset. Experiments on 7B-parameter instruction and reasoning models show that DRIFT consistently raises the performance ceiling on both, outperforming existing data curation baselines.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：监督微调（Supervised Fine-Tuning, SFT）中，训练数据的分布直接影响LLM的性能上限。现有的数据筛选方法（如DSIR、LESS等）主要关注在受限预算下加速训练，但面对已经充分训练的模型时，它们难以进一步提升模型的能力天花板。
- **背景**：现有数据筛选范式包括领域级混合、数据选择（效率优先）和在线批次调度，但这些方法要么粒度粗糙，要么专注于效率而非能力提升，要么破坏训练管线。论文关注一个实际但未被充分探索的场景：在模型已完全收敛于原始SFT数据集后，如何通过数据归因重新校准分布，突破饱和状态。
- **核心挑战**：需要一种稳健的归因机制，评估每个训练样本对模型贡献，而标准影响力函数（Influence Functions, IF）在LLM应用中存在两个结构性脆弱性：
  1. **近邻鸿沟（Proximity Gap）**：使用外部参考（off-policy）作为验证目标会导致较大的参数偏移，破坏IF的局部泰勒近似假设。
  2. **梯度范数偏差（Gradient Norm Bias）**：原始IF分数严重受梯度范数影响，易偏向异常样本，而非真正有用的样本。

## 2. 方法论：核心思想、关键技术细节、公式/算法流程

### 核心思想
**DRIFT（Data Refinement via On-Policy Influence Functions for Supervised Fine-Tuning）** 利用模型自身的在线策略生成（on-policy rollouts）作为验证目标，替代传统外部参考，从而减轻近邻鸿沟；并引入符号加权和梯度去偏机制，使少量验证查询能可靠地归因整个SFT数据集，最终通过对高影响力子集进行持续微调来提升模型能力。

### 关键技术细节（四步流程）

#### 步骤1：在线策略近邻验证构建（On-Policy Proximal Validation Construction）
- 使用已充分收敛的基础模型θ*，对一组验证查询Xval进行采样，生成在线策略生成集Zrollout = {(x, y) | x∈Xval, y~πθ*(·|x)}。
- 将这些生成作为IF的验证目标，其梯度信号更贴近当前参数流形，减少所需参数偏移。

#### 步骤2：策略梯度IF公式（Policy Gradient IF Formulation）
- 将验证目标定义为最大化期望奖励。对每个生成赋予离散奖励y_val∈{+1, -1}（正确为正，错误为负），梯度近似为REINFORCE策略梯度估计：
    ∇θ J_PG ≈ (1/N_x) Σ_i y_val^(i) ∇θ log πθ*(y^(i) | x)
- 使用GraSS稀疏随机投影将高维梯度映射到低维空间ϕ(z;θ*)∈R^d。
- 任务k的原始影响得分通过中心化加权点积计算：
    S_raw^(k)(z_train) = ϕ(z_train)^⊤ · (Σ_{z_val∈D_k} w(z_val) ϕ(z_val))
  其中w(z_val) = y_val / (|D_k|·N_x)。

#### 步骤3：影响去偏（Influence Debiasing）
- 原始得分与梯度范数呈幂律关系（|S|∝||ϕ||^β, β≠1）。采用**逐任务对数空间正交化**：
  1. 对每个任务k，在log尺度上对绝对原始得分与梯度范数做线性回归，提取斜率β^(k)。
  2. 对底部10%极小梯度范数的样本进行掩码。
  3. 去偏得分：˜S^(k) = sign(S_raw^(k)) · exp(log|S_raw^(k)| - β^(k) log||ϕ||)
- 最终得分S(z_train) = Σ_k ˜S^(k)(z_train)。

#### 步骤4：基于精炼分布的持续训练（Continual Training with Refined Distribution）
- 按S(z_train)降序排列所有训练样本，选择前10%（默认）构成精炼数据子集。
- 在基础模型θ*上使用该子集进行持续SFT，突破原始模型的能力饱和。

## 6. 主要结论与发现

1. **DRIFT持续提升性能上限**：在两种7B模型上，DRIFT在所有8个benchmark的平均得分上均超过所有基线，特别是在非目标域上也取得显著增益（Olmo3: +1.14%，OpenR1: +2.49%），表明其泛化性强。
2. **传统效率型方法失败**：DSIR、LESS、RDS等多数方法无法超越随机基线，甚至导致性能下降。这印证了在完全训练模型上，效率导向的选择不足以打破饱和。
3. **在线策略验证目标至关重要**：使用外部参考的标准IF几乎无提升，而DRIFT使用模型自生成作为验证锚点，显著改善归因质量。
4. **自我蒸馏（Self-Distillation）性能崩溃**：直接使用在线生成微调会导致严重过拟合和性能下降（OpenR1平均57.23%→49.33%），而DRIFT仅将生成作为归因锚点，保留了数据多样性。
5. **去偏策略有效**：对数空间正交化优于余弦相似度和打包校正等启发式方法，能有效抑制梯度范数偏差，将异常样本推离头部。
